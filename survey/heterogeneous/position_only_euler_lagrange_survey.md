## 0. 结论先行

一句话：

> **EL 系统"只用位置测量"的本质不是"少测一个状态"，而是把速度信息变成必须自行构造的估计量；因此所有方法的分歧点只有一个——速度从哪里来，以及这个估计是否进入稳定性证明。**

由此形成 5 条互不等价的技术路线（详见 §2），知识库中被明确证实"仅位置"的 EL 论文共 **19 篇**（含 1 本专著；[#883] 因控制律式 (5) 含实测 \(\dot q_i\) **已剔除**，见 §5.1 批注），分布如下：

| 层级 | 篇数 | 代表 |
|---|---|---|
| 多 EL 智能体：一致 / 编队 / 包含 / 合围 | 7 | [#173]、[#3879]、[#2636]、[#1978]、[#2815]、[#75]、[#2695] |
| 单机械臂 / 机械系统输出反馈 | 8 | [#180]、[#532]、[#831]、[#3238]、[#2422]、[#1911]、[#3241]、[#1844] |
| 空间机械臂 | 1 | [#151] |
| 理论专著 | 1 | [#3740] |
| 同族（非完整机器人，非标准 EL） | 2 | [#1933]、[#2391] |
| **合计** | **19** | — |

**最重要的三个发现**：

1. **"异构（H2+）EL + 仅位置测量"在知识库中是空的**。异构 EL 的论文（[OKB #2023]、[OKB #2384]、[OKB #2832]、[OKB #2870]、[OKB #2411]、[OKB #3906]）全部默认速度可测或全状态反馈；而仅位置测量的 EL 论文（[OKB #173]、[OKB #3879]、[OKB #1978]、[OKB #2636]）最多到 **H1（参数可不同，但自由度与结构相同）**。两条线的交集即为可写的空白（§7）；领导 / 目标结构的盘点见 §6.2。
   > ⚠ **口径提醒**：若把"参数不同"也算异构（H1），则 [#173]/[#3879]/[#2815]/[#2695] 本身就是"弱异构 + 位置-only"，上述空白就要改成 **H2（\(n_i\) 不同）+ 位置-only** 才是真空白。两套口径不可混用，定义与逐篇标注见 **§6.0**。
2. **位置-only + 合围/包含只有 1 篇**：[OKB #2695]（黑龙江大学硕士论文，输入受限 EL 包含控制，不依赖相对速度）是唯一真正合格的一篇。常被引为对照的 [OKB #883]（AJC 2026，EL + 移动目标 fencing）**实际上用了本机测速 \(\dot q_i\)**（式 (5)），严格属"只交换相对位置"而非"无速度测量"，详见 **§5.1 批注**。
3. **位置-only 的收敛性普遍弱一档**：全状态反馈下常见的"渐近/有限时间"在位置-only 下退化为"半全局 / 半全局预设时间 / UUB"。原因见 §2.4 的"半全局性来源"。

## 1. 问题界定：什么才算"只用位置测量"

EL 模型：

$$
M_i(q_i)\ddot q_i + C_i(q_i,\dot q_i)\dot q_i + G_i(q_i) = \tau_i
$$

"仅位置"在文献中有 **5 种强度不同**的表述，写作时必须明确选哪一种，否则对比会失真：

| 等级 | 测量假设 | 知识库中的典型表述 | 难度 |
|---|---|---|---|
| L0 | 位置 + 速度全测 | "full state feedback" | 基准 |
| L1 | 位置可测，速度**可由差分/已知模型**得到 | "without velocity sensors but with known dynamics" | 低 |
| L2 | 位置可测，速度**不可测且模型参数未知** | "using only position measurements" | 中 |
| L3 | **只有相对位置**（无全局坐标、无邻居速度） | "only relative position information is exchanged" | 高 |
| L4 | 位置本身含噪 / 只有部分分量 / 采样保持 | "limited model information", "sampled-data", "pose-only" | 最高 |

知识库明确落在 **L2/L3** 的 EL 论文：`[#173] #3879 #2636 #1978 #2815 #2695 #75 #180 #532 #831 #3238 #2422 #1911 #3241`；落在 **L4**：`[#151] #1844`；`[#1933] #2391` 属非完整机器人（同族但非标准 EL）；`[#3740]` 为理论专著。

> **L3 的常见误判（点名 [OKB #883]）**：摘要里 "using only the relative position information of the target and the agents" 极易被读成"无速度测量"。但 L3 只约束**通信 / 互测的量**（不交换速度、不用全局坐标、不用 Global Positioning），并不禁止**本机速度可测**。[#883] 的式 (5) 中 \(Y_i(q_i,\dot q_i,\dot\nu_i,\nu_i)\)、\(-(\dot q_i-\nu_i)\) 与自适应律里的 \(\Delta\nu_i=\dot q_i-\nu_i\) 都直接用了 \(\dot q_i\)，其正文也自述 "each agent utilizes only its own position **and velocity**"。因此判据应是：**看控制律 / 自适应律 / Lyapunov 函数里有没有实测 \(\dot q_i\)**，而不是看摘要里的 "only relative position"。（详细批注见 §5.1）

> 注意：`[OKB #38] #232 #1955 #63 #3906 #2642 #624 #3232 #3236 #2814` 等 EL 论文虽频繁出现"无速度测量"字样，但其**上下文均为参考文献列表**，正文采用全状态或对领导者做状态观测，不属于本次范围（已逐篇核校摘要）。

## 2. 五条技术路线

### 2.1 路线 A：显式速度估计器 + 位置反馈控制器（"观测-控制分离"）

先构造 $\hat{\dot q}_i$，再代入常规协议。子类：

- **线性/高阶滤波（velocity filter）**：`[#173]` 用速度滤波器 + 三阶线性参考模型，把一致性转成轨迹跟踪；`[#3879]` 为每个智能体配一个速度估计滤波器，再叠加时变增益矩阵实现预设时间。
- **高增益观测器**：`[#2815]` 对领导者/跟随者分别配高增益观测器，外层配有限时间滑模估计器 + 自适应 NN 处理模型不确定性，收敛性为 UUB；`[#151]` 用高增益观测器估计空间机械臂速度，配 BLF + RBFNN。
- **二阶滑模 / 有限时间微分器**：`[#2636]` 先用"相对位置 + 相对速度"设计有限时间协议，再用二阶滑模观测器把相对速度替换为仅相对位置的版本。
- **降阶自适应速度观测器**：`[#3238]`（T-RA 1995）降阶 + 对未知参数自适应；`[#831]`（Automatica 2004）不连续速度观测器 + 不连续输出反馈，半全局渐近。
- **齐次性有限时间速度观测器**：`[#75]` 固定时间速度观测器 + 固定时间加权质心估计器 + 滑模面。

- **优点**：与既有全状态协议兼容，工程上可"打补丁"；观测器误差可单独分析。
- **代价**：**分离原理在非线性 EL 下不成立**，必须做级联/Lyapunov 联合证明；高增益带来峰值现象（peaking）与噪声放大，因此普遍只能得到半全局结论。

### 2.2 路线 B：能量整形 / 无源性（passivity-based）——不显式估计速度

控制器本身被设计成另一个 EL 系统，与对象通过势函数梯度互联，用阻尼注入代替速度反馈：

- `[#1978]`（IJRNC 2019，Cruz-Zavala / Nuño / Moreno）：势能与耗散函数取齐次形式 ⇒ **有限时间**收敛，无速度测量，leaderless + leader-follower 一致。
- `[#3740]`（专著）：Passivity-based Control of EL Systems，是这一路线的理论母本。
- `[#1933]`（TAC 2023）：port-Hamiltonian 框架 + **动态扩张（dynamic extension）**，把速度项消掉，仅位置测量下做轨迹跟踪与编队；可处理环状（ring）非无圈子图。

- **优点**：不需要精确模型，鲁棒性好；证明中速度误差**不出现**，避免级联问题；物理意义清晰（能量）。
- **代价**：需要 EL 的结构性质（反对称性 $\dot M-2C$、无源性）；对**有向图**和**输入饱和**较难扩展（`[#3879]` 在引言中明确指出该路线"主要限于无向网络"）。

### 2.3 路线 C：模型无关 / 自适应（model-independent）

不辨识模型、不估计参数，靠自适应增益 + 滑模/PI 吃掉未知项：

- `[#532]`（ICRA 2007，Su/Müller/Zheng）：**仅位置反馈的 PID**，全局渐近稳定（Lyapunov + LaSalle），显式给出增益条件，控制器不含模型信息。
- `[#2422]`（AJC 2015，Driessen）：观察器/控制器联合设计，全局**指数实用**稳定（GEPS），观测器更新不连续但力矩连续。
- `[#3241]`（TMech 2020）：把"关节速度测量不确定"当成待重构的量，自适应律只用关节位置 + 重构信息，含执行器故障，实验验证。
- `[#2695]`（2021 硕士论文）：EL 多机械系统在**输入受限**下的分布式包含控制，不依赖相对速度；后续章节用自适应神经网络做非线性包含与容错。

- **优点**：最贴近工程（PID 级实现复杂度）；对参数不确定/故障最鲁棒。
- **代价**：多为**调节/跟踪**问题而非协同问题；协同版本往往只能得到 UUB 或实用稳定，且增益整定靠试。

### 2.4 路线 D：预设/固定时间 + 位置反馈（时间规格化）

把"速度不可测"与"时间可指定"两个难点叠加：

- `[#3879]`（IEEE TIE 2026，Shi/Lin/Feng/Wang/Dong/Ren）：**预设时间时变编队 + 仅位置测量**，速度估计滤波器 + 时变增益矩阵，有向拓扑，**半全局**预设时间，含实验验证。
- `[#75]`（Nonlinear Dynamics 2024）：固定时间加权质心编队跟踪，无速度测量，含质心估计器。
- `[#2870]`：固定时间 EL 同步（全状态），可作为"若要位置-only 需补哪一环"的对照。

- **要点**：位置-only 下"半全局"几乎不可避免——因为高增益/滤波器的初始误差必须被先验界压住，才能保证不越界。

### 2.5 路线 E：安全/约束下的位置-only（最前沿、最薄弱）

- `[#1844]`（CDC 2023，Wang & Xu）：EL 系统 + 有限模型信息 + 测量不确定。把 EL 分解为 **proxy 子系统** 与 **virtual tracking 子系统**：前者用 CBF 保证受控不变性，后者用 BLF 保证安全速度跟踪误差有界。
- `[#151]`（Acta Astronautica 2021）：自由漂浮空间机械臂，BLF 保证预设性能，输出反馈用高增益观测器。

- **意义**：这条线把"位置-only"和"避碰/安全"接起来，正是**合围**所必需的两件事（包围 + 不撞），但知识库中 **"EL + 位置-only + 合围 + 安全"四者同时出现的论文为 0 篇**。

## 5. 合围 / fencing / 包围：EL + 位置-only 的真实存量（1 篇）

合围类论文在知识库中很多（[OKB #2278] #231 #563 #773 #779 #852 #1111 #1976 等），但**绝大多数是二阶积分器或线性模型**；既用 EL 动力学、又真的**不测本机速度**的合围/包含工作只有 1 篇：

| OKB | 文献 | 年 / 期刊 | 模型 | 测量假设 | 关键技术 | 结论 |
|---|---|---|---|---|---|---|
| [#2695] | 徐廷铷 — *多智能体系统的分布式合围控制* | 2021，黑龙江大学（硕士） | EL 多机械系统 | **不依赖相对速度**（输入受限） | 输入受限下的分布式协议 + 观测器型自适应 NN | 跟随者收敛到领导者凸包（**包含**语义的合围）；后续章节含执行器偏移故障容错 |

### 5.1 批注：[OKB #883] 的"只用相对位置"≠"只用位置测量"（存疑项，勿直接引用）

> **结论先行**：[#883]（Zhao et al., *Flexible distributed fencing control for Euler–Lagrange MAS with moving target*, AJC 2026）**不属于"仅位置测量"**。它满足的是"只交换相对位置信息（无需全局位置、无需邻居速度）"，而**本机速度 \(\dot q_i\) 是可测并被直接使用的**。本文已将其从 §0/§1/§5 的 position-only 清单中剔除，重新标注为 **L3′（相对位置通信 + 本机测速）**。

**依据（均可复核，`read_markdown(id=883)`）**

1. **控制律式 (5) 三处含 \(\dot q_i\)**：
   $$u_i=\hat u_i+Y_i\big(q_i,\underline{\dot q_i},\dot\nu_i,\nu_i\big)\hat\theta_i,\qquad
   \hat u_i=-\sum_{j=0}^{n}\frac{\partial V_{ij}}{\partial q_i}-k_1(q_i-q_0)-\big(\underline{\dot q_i}-\nu_i\big)$$
   自适应律 \(\dot{\hat\theta}_i=-\Gamma_iY_i^{T}(q_i,\underline{\dot q_i},\dot\nu_i,\nu_i)\Delta\nu_i\)，其中 \(\Delta\nu_i=\underline{\dot q_i}-\nu_i\)（即式 (4) 的速度误差）——**三项都需要实测 \(\dot q_i\)**。
2. **回归参数化也在实际速度处取值**：式 (10) \(M_i(q_i)\dot\nu_i+C_i(q_i,\underline{\dot q_i})\nu_i+g_i(q_i)=Y_i(q_i,\underline{\dot q_i},\dot\nu_i,\nu_i)\theta_i\)；若 \(\dot q_i\) 不可测，这里必须先换成估计值或滤波变量。
3. **Lyapunov 函数本身就是速度误差**：式 (13) 的 \(V_1=\tfrac12\sum\Delta\nu_i^{T}M_i\Delta\nu_i+\dots\)、\(V_4\) 均含 \(\Delta\nu_i=\dot q_i-\nu_i\)，说明**证明本身依赖实测速度**，不是"估计速度进入证明"。
4. **作者自己也这么写**：正文明确说 "each agent utilizes only its own position **and velocity**, the position of the target, and the estimation of the target's velocity"。所以摘要的 "only the relative position information" 与正文并不矛盾——它指的是**信息交换/几何量**（target–agent 相对位置），而不是**传感器配置**。

**因此**：

- 该文的真实环境是：本机 \(q_i,\dot q_i\) 可测；邻居只给相对位置；目标只给相对位置且速度未知（用 \(\nu_i\) 估计）。
- 引用其 **fencing 结构**（凸包/无标签/柔性编队）是安全的；但引用其作为"**EL 合围可以位置-only 实现**"的**证据则不成立**。
- 若要把它接到位置-only 内环，必须先做两步替换：(i) 把 \(\dot q_i\) 换成速度滤波器输出（[#173]/[#3879]）或直接用能量整形的阻尼注入（[#1978]）；(ii) 把 \(\Delta\nu_i\) 换成"伪速度误差" \(\eta_i\)。这两步会同时改变自适应律形式与 \(V_1\) 的结构，**不是简单代换**。
- 附加瑕疵（顺带记录）：式 (16) 的证明用到 \(\dot q_0\)（目标速度），而目标速度是"未知但常值"，文中用 \(\nu_i\) 替代的处理在符号上不严谨。

**对照（非 EL，但同一问题结构，可作为技术借用来源）**：
- 二阶积分器 + 位置-only 合围/包围：[OKB #1111]（有/无速度测量两版协议）、[OKB #231]、[OKB #563]、[OKB #2278]（label-free 刚性编队）、[OKB #773]（label-free fencing）、[OKB #2860]（未知机动目标 + 相对位置估计器）。
- 双层 UAV 目标 fencing：[OKB #149]（相对测量）。
- 综述与专著：[OKB #1976]（*Multi-robot systems: Coordinated fencing control and applications*）。

> **差距点**：#2695 是包含而非"抗逃逸"围捕；#883 又并非 position-only 且只处理**常值速度**目标。因此 **"EL + 未知时变机动目标 + 仅位置 + 输入饱和 + 避碰"仍是空位**——这正是 `survey/heterogeneous/` 这条线可以推进的位置（领导/目标结构的完整盘点见 §6.2）。

## 6. 与"异构"的交叉：为什么这是一个空位（也是本文放在此目录的原因）

### 6.0 异构的定义（本文口径，先说清楚）

"异构"在文献里没有统一阈值：很多应用论文把"参数不同"直接叫 heterogeneous，也有审稿人只认"阶次/模型类别不同"。为了不让后面的计数产生歧义，本文采用与 `heterogeneous_models_survey.md` §1 一致的分级口径：

| 等级 | 名称 | 含义（以 EL 为例） | 本文是否算"异构" |
|---|---|---|---|
| **H0** | 全同（identical） | \(M_i,C_i,G_i\) 连参数都相同 | 否 |
| **H1** | **参数异构（parametric，弱异构）** | 结构形式与**自由度相同**，仅 \(M_i,C_i,G_i\) 的参数不同或未知 | **否**（计作"弱异构"，单独标注） |
| **H2** | **结构 / 维数异构** | \(n_i(=p_i)\) 不同、\(C_i\) 形式不同、相对阶/输入矩阵不同、mixed-order | **是** |
| **H3** | 模型类别异构 | EL 与积分器 / 非完整 / LTI / PDE-ODE 混合 | 是 |
| **H4** | 平台 / 能力异构 | UAV-USV-UUV 跨域、感知半径 / 饱和 / 通信能力不同 | 是（系统级） |

**为什么要以 H2 为界（判据：控制设计是否需要逐智能体重做）**

- **H1 下模板可复用**：同一个 \(p\)、同一个回归矩阵结构、同一个滤波器阶数。以 [#173] 为例，\(k_{wi}\) 公式里虽有 \(\underline m_i,\zeta_{i,1},\zeta_{i,2}\)，但**只是换数值**，公式形状不变；参数未知用自适应 \(\hat\theta_i\) 吃掉即可。
- **H2 下必须重做**：\(p_i\) 不同 ⇒ 状态空间维数不匹配，状态同步无定义，凸包/编队参考只能定义在**位置（输出）空间**；Lyapunov 函数无法统一构造（\(\eta_i\) 维数随 \(p_i\) 变）。难度是阶跃而非渐变。

> ⚠ **写作时必须显式声明口径**。若采用宽口径（H1 也算异构），则 [#173]、[#3879]、[#2815]、[#2695]、[#883] 全都属于"异构 + 位置-only"，本文的"空白"结论就不再成立；真正站得住的空白是 **H2+H3 + 位置-only**。两套说法都能发表，但不能在正文里混用。

**本批文献的 H 标注（已逐篇核过模型方程）**

| 论文 | H 等级 | 依据 |
|---|---|---|
| [#173] | H1（结构同、\(p\) 同、\(\theta_i\) 未知） | 单一 EL 方程，\(q_i\in\mathbb R^p\)，界常数按 \(i\) 下标给出 |
| [#3879] | H1 | 同上；Property 1–4 对全体共用 |
| [#2815] | **H1（不是异构）** | 单一 EL 方程，同一个 \(p\)；Property 1 的 \(k_{\underline m},k_{\overline m}\) **不写下标**（全体共用），差异由自适应 NN 吸收。其"两层"是**角色分层（领导者/跟随者）而非模型异构** |
| [#2695] | H1 | 多 EL 机械系统，同一维数，差异在参数与非线性项 |
| [#883] | H1 | 未知动态参数，同一维数（另见 §5.1：它并非位置-only） |
| [#1978] | H0/H1 | 全驱动保守 EL，同一 \(n\)、同一拉氏结构 |
| [#2636] | H0/H1 | 同一 EL 方程族 |
| [#2023] [#2384] [#2832] [#2870] [#2411] [#3906] | 文献自称 heterogeneous，按本文口径**至少 H1**；**是否达 H2（\(n_i\) 不同）尚未逐篇核实**——若仅为 H1，则它们与位置-only 的"交集为空"只是事实层面（它们都没做位置-only），而不是结构层面的不可能 |

> 测量等级 L（§1）与异构等级 H（本节）是**两个正交维度**：L 回答"测什么"，H 回答"各智能体模型差多少"。任何一篇文献都应同时给出两元组，例如 [#173] = (L3, H1)、[#2815] = (L2, H1)、[#883] = (L3′, H1)。

### 6.1 知识库事实

|---|---|---|
| [#2023] 多异构 EL 任务空间预设时间编队跟踪 | 参数 + 任务空间 | ❌ 全状态 |

### 6.2 领导 / 目标结构盘点：这批论文里"谁在主导、谁在被围"

"多 EL 系统协同"不等于"无领导者"。把 §3/§5 的核心文献按**领导 / 目标结构**重排后，可以看到一个很清晰的谱系：

| OKB | 领导 / 目标结构 | 领导者（目标）状态怎么来 | 领导者速度假设 |
|---|---|---|---|
| [#173] | **真·无领导**（leaderless consensus，标题即 leaderless） | 无 | — |
| [#3879] | **无外部领导者**：TVF 由"虚拟系统 + 编队偏移 \(h_i\)"自生成，本质仍是 leaderless 编队 | 无 | — |
| [#1978] | 两版都做：leaderless + leader-follower；但其 leader 是**给定常值坐标**（regulation 到定点） | 常值 | 速度为 0 |
| [#2636] | 两版：(i) leaderless 版跟踪一个 **target location**（常值）；(ii) **动态领导者**版 | (ii) 分布式**有限时间估计器**重构领导者状态 | 估计得到 |
| [#2815] | **动态领导者 + 两层编队-包含** | 只有部分跟随者可测到领导者输出 ⇒ 有限时间滑模估计器估**位置 + 速度** | 估计得到 |
| [#2695] | **多领导者**（凸包/包含，中文语境即"合围"） | 领导者轨迹给定 | 给定 |
| [#883] | **单非合作移动目标**（fencing，本批唯一真正的"被围者"） | 相对位置（**本机速度可测**，见 §5.1） | **未知但常值** |
| [#75] | 虚拟领导者 = **加权质心**（可沿任意连续参考轨迹） | 固定时间质心估计器（相对测量） + 速度观测器 | 估计得到 |

由此可得三点判断：

1. **"有领导者"的 EL 协同论文其实很多，但它们全都不是 position-only**。异构 EL 那条线（[#2832] 未知领导者、[#2384]、[#2023]、[#2870]、[#2411]）默认全状态反馈，"领导者速度"这一环根本不用处理——这正是两条线不相交的机制性原因，而非巧合。
2. **位置-only 与"动态领导者"存在结构性张力**：领导者的速度也必须估。#2636、#2815 用分布式观测器补；#3879 干脆取消外部领导者，让参考信号由本机虚拟系统解析生成；#173 连参考都是本机三阶模型。规律是：**越靠"无领导 / 自生成参考"，位置-only 越好做**。
3. **"非合作目标"在本批中只有 1 篇**：[#883]，且必须假设目标**匀速**，且它**并非位置-only**（用到本机 \(\dot q_i\)，见 §5.1）。目标一旦机动，就要再加一层目标状态估计器（可对照非 EL 的 [#2860] 的相对位置估计器），而这一层在 EL + 位置-only 下**尚无实现**。

> 结论：多 EL 协同中"无领导"只是 [#173]/[#3879] 两支，其余都有领导或目标；但**"仅位置测量"这个子集里，确实没有任何一篇处理"非合作机动目标 + 合围"**——与 §6.1 的结构异构空位叠加，构成本文认定的双空白。

### 6.3 三条真正会"打架"的地方（写作时的贡献点）

1. **速度估计器要为不同自由度/结构各设计一次**：同构时一个滤波器模板可复用（[#173]）；异构时 $n_i$ 不同、$M_i$ 结构不同，滤波器阶数与增益无法统一 ⇒ "全分布式 + 无全局增益"更难。
2. **位置-only 把"输出"降到位置**，而异构下的凸包/编队参考本身只能定义在**输出空间**（参见 `heterogeneous_models_survey.md` §5.4 与 `heterogeneous_swarm_encirclement_challenges.md` §2.1）。于是"输出凸包 + 位置反馈"是唯一自洽的表述，但其**充要条件在知识库中尚属空白**。
3. **半全局性 vs 异构性**：位置-only 的证明普遍依赖"初始误差有界"（半全局）；异构初值分布更散，半全局前提更难满足 ⇒ 需要**预设时间/预设性能**把瞬态钉住（[#3879]、[#151] 是这个思路的两个样本）。

### 6.4 可直接复用的六个技术模块

| 需求 | 可借用 | 出处 |
|---|---|---|
| 无模型速度/阻尼构造 | 能量整形 + 阻尼注入（无需估计速度） | [#1978]、[#3740] |
| 有向图 + 全分布式 | 模型参考自适应 + 速度滤波器 | [#173] |
| 时间规格化 | 时变增益矩阵 + 预设时间滤波器 | [#3879] |
| 输入受限下的包含/合围 | 受限协议（不依赖相对速度） | [#2695] |
| 安全（避碰 + 速度约束） | proxy（CBF）+ virtual tracking（BLF）双层 | [#1844]、[#151] |
| 合围 + 无标签 + 未知参数 | 柔性 fencing + 自适应（**需先替换本机速度项**，见 §5.1） | [#883] |

## 7. 选型建议（若要做"异构 EL + 仅位置 + 合围"）

1. **模型层**：EL 写 $M_i(q_i)\ddot q_i+C_i\dot q_i+G_i=\tau_i$。按 §6.0 口径，**H1（仅参数不同）**只需在 $(M_i,C_i,G_i)$ 的数值/未知性上体现；真正的**异构 H2** 体现在 **$n_i$（自由度）不同**。后一种情形下合围只能定义在**位置输出空间**，不要试图做状态凸包。
2. **速度层**：优先 **能量整形**（[#1978]/[#3740]）——证明中根本不出现速度误差，天然适配异构（每个智能体用自身 EL 结构做整形）；若必须有向图与全分布式，退回 [#173] 的滤波 + 自适应参考模型。
3. **时间层**：用 [#3879] 的时变增益把收敛压到预设时间，否则半全局结论在异构初值下不可用。
4. **约束层**：用 [#1844] 的双子系统把避碰（CBF）与速度跟踪（BLF）解耦；合围的凸包约束可用 [#883] 的柔性 fencing 形式，**但其控制律含实测 \(\dot q_i\)，需先把该速度项换成滤波器/观测器输出，才能与位置-only 自洽（见 §5.1）**。
5. **可发表的空白**：把 2–4 组合，给出**异构 EL（H2：$n_i$ 可不同）在仅位置测量下的输出凸包含/合围**判据，并处理未知时变机动目标 + 输入饱和。目前知识库无此类结果。（若只做 H1，则等于在 [#173]/[#3879] 上叠加合围，创新性需另行论证。）

# 附录：两篇代表作如何做到"只用位置测量"（#173 / #3879 精读）

只读摘要会以为两篇都在"估个速度"，读完全文才发现它们做的是两件不同的事：**#173 根本不估计速度，它用参考模型把速度"替换"掉；#3879 则用预设时间增益把"估计误差"强行压到零**。下面按"要消掉哪几个速度依赖 → 怎么消 → 代价是什么"逐步拆。

## A.1 先明确："只用位置"要消掉 3 个速度依赖

以 EL 方程\(M_i(q_i)\ddot q_i+C_i(q_i,\dot q_i)\dot q_i+g_i(q_i)=u_i\) 为例，控制器里有三处天然需要 \(\dot q_i\)：

| 坎 | 出现位置 | 后果 |
|---|---|---|
| **C1：跟踪误差的导数 \(\dot e_i\)** | Lyapunov 函数、自适应律、滤波器动态 | 若直接对 \(q_i-z_{i,1}\) 差分，噪声被放大，且无法进入严格证明 |
| **C2：邻居速度 \(\dot q_j\)** | 一致性协议里的 \(\sum_j a_{ij}(\dot q_i-\dot q_j)\) | 即使自己装了编码器，也要求邻居测速 → 违背分布式 |
| **C3：参考信号的导数** | 参考/虚拟信号的 \(\dot z_{i,1},\ddot z_{i,1},z_{i,1}^{(3)}\) | 若参考信号由"滤波位置"生成，其导数不可用；若由控制器内部的模型生成，则可解析得到 |

两篇的**共同策略**是：把 C3 交给"内部参考模型（解析可微）"，把 C1/C2 交给"一阶辅助滤波器 + 伪速度误差 \(\eta_i\)"。差别在于增益怎么调度、以及参考信号用几阶。

## A.2 [OKB #173]（Meng et al., TAC 2023）：三阶参考模型 + 速度滤波器 + 自适应律积分化

### 第 1 步：用三阶线性参考模型替换"本机速度"（消 C3）

为每个智能体设计（原文式 (15)）：

$$
z_{i,1}^{(3)}+\Big[2k_i+\tfrac{1}{k_i}\textstyle\sum_j a_{ij}(t)\Big]\ddot z_{i,1}+\Big[k_i^2+2\textstyle\sum_j a_{ij}(t)\Big]\dot z_{i,1}=-k_i\textstyle\sum_j a_{ij}(t)\,\big(q_i-q_j\big)
$$

要点：

- 驱动项只有**相对位置** \(\sum_j a_{ij}(q_i-q_j)\)——连邻居速度都不用交换（**消 C2**）。
- \(z_{i,1},\dot z_{i,1},\ddot z_{i,1},z_{i,1}^{(3)}\) 全部由该微分方程**本地数值积分**得到，是"控制器内部状态"而非测量量（**消 C3**）。
- 辅助变量 \(z_{i,2}=\tfrac{1}{k_i}\dot z_{i,1}+z_{i,1},\; z_{i,3}=\tfrac{1}{k_i}\dot z_{i,2}+z_{i,2}\)（式 (16)）把三阶系统化成
  $$\dot z_{*,1}=-(K\otimes I)z_{*,1}+(K\otimes I)z_{*,2},\quad \dot z_{*,3}=(K^{-1}\mathcal A)z_{*,1}-(K^{-1}\mathcal D)z_{*,3}+\Delta$$
  即**一阶积分器形式**，从而可以整段复用"切换有向图 + 联合连通 ⇒ 指数一致"的成熟引理（原文 Lemma 2.1/3.1）。这一步是把非线性问题"降维"成图论问题的关键，也是它敢处理**切换有向图**的原因。
- 参考模型初值 \(z_{i,1}(0)=q_i(0)\)，\(\dot z_{i,1}(0)\) 取"接近 \(\dot q_i(0)\)"，\(\ddot z_{i,1}(0)=0\)——注意这里**仍需要一次初始速度的粗略猜测**（工程上取 0 也可，只是初值误差进吸引域）。

### 第 2 步：一阶速度滤波器把 \(\dot e_i\) 从控制律里"吸收"掉（消 C1）

定义跟踪误差 \(e_i=q_i-z_{i,1}\)，再定义（原文式 (22)）：

$$
y_i=w_i-k_{wi}e_i,\qquad \dot w_i=-(k_{wi}+1)w_i+(k_{wi}^2+1)e_i+\dot k_{wi}e_i,\quad w_i(0)=k_{wi}(0)e_i(0)
$$

求导后 \(\dot e_i\) **恰好被 \(k_{wi}\dot e_i\) 抵消**：

$$
\dot y_i=-k_{wi}\dot e_i-(k_{wi}+1)y_i-(k_{wi}-1)e_i\;\Longrightarrow\;\dot y_i=-y_i+e_i-k_{wi}\eta_i
$$

再定义

$$
\boxed{\eta_i=y_i+e_i+\dot e_i}\qquad\Longleftrightarrow\qquad \dot e_i=\eta_i-e_i-y_i
$$

这就是全文的枢纽：\(\eta_i\) 是**不可测**的，但它只是一个"证明用的合成变量"；实际实现只需要 \(y_i\)（由可测的 \(e_i\) 驱动滤波器得到）。于是控制律里凡是需要 \(\dot e_i\) 的地方，都可以用 \(\eta_i-e_i-y_i\) 表示，而 \(\eta_i\) 会被 Lyapunov 证明"压到零"。

### 第 3 步：控制律 + 把自适应律改写成"积分形式"（否则仍然需要 \(\dot e_i\)）

控制律（原文式 (36)），**只含 \(q_i\)（经 \(e_i\)）、\(y_i\)、参考模型解析量与 \(\hat\theta_i\)**：

$$
u_i=Y_{zi}(z_{i,1},\dot z_{i,1},\ddot z_{i,1})\,\hat\theta_i+k_{ei}k_{wi}\,y_i-k_{ei}\,e_i
$$

其中 \(Y_{zi}\theta_i=M_i(z_{i,1})\ddot z_{i,1}+C_i(z_{i,1},\dot z_{i,1})\dot z_{i,1}+g_i(z_{i,1})\) 是**在参考轨迹上取值**的回归矩阵（不是在实际状态上取值——这正是不需要 \(\dot q_i\) 的根源）。

自适应律本来写成 \(\dot{\hat\theta}_i=-\Gamma_iY_{zi}^{\top}\eta_i\)（式 (37)），**但 \(\eta_i\) 含 \(\dot e_i\)，不可实现**。作者用分部积分把它改写成（式 (38)）只含 \(y_i,e_i\) 与参考量的积分形式：

$$
\hat\theta_i(t)=-\Gamma_i\!\int_0^t\!\Big[Y_{zi}^{\top}(y_i+e_i)-\dot Y_{zi}^{\top}e_i\Big]\mathrm d\tau-\Gamma_i\gamma_{2i}^{\top}\epsilon_*+\hat\theta_i(0)
$$

> **这是全文最容易被忽略的一步**：很多人复现时卡在"\(\eta_i\) 里有 \(\dot e_i\)"，作者靠"积分形式 + 分部积分"把 \(\dot e_i\) 换成了 \(\dot Y_{zi}\)（参考模型的解析导数）。同类技巧在 #3879 中被直接采用为**默认写法**（见 A.3 第 3 步）。

### 第 4 步：为什么能"全分布式"，又为什么只能"半全局"

- **全分布式（无 Laplacian 特征值）**：时变增益取（式 (43)）
$$
k_{wi}(t)=\frac{k_{zi}\zeta_{i,2}^2}{4\underline m_i}\big(1+\|\dot z_{i,1}\|^2+\|\dot z_{i,1}\|^4+\|\ddot z_{i,1}\|^2\big)+\frac{k_{ei}}{\underline m_i}+\alpha_i
$$

  只依赖**自身参数界**与**自身参考轨迹**；\(k_{ei}\) 由式 (47) 用本地初始误差上界 \(\bar V_i(0)\) 定，同样不含全局信息。这是它相对 [22][23]（需特征值）的主要卖点。
- **半全局**：Assumption 3.2 要求初始速度误差 \(\|\dot e_i(0)\|\le\bar{\dot e}_i\)、初始参数误差有界，用于确定 \(k_{ei}\) 与吸引域
  $$\Omega_i=\Big\{V_i<\tfrac{k_{zi}}{\beta_i}\big(k_{ei}-\zeta_{i,1}-\tfrac{3}{k_{zi}}\big)\Big\}$$
  所以结论是"从 \(\Omega_i\) 内出发"的，不是全局。

### 第 5 步：证明链条（4 行说完）

取 \(V_i=\tfrac12\eta_i^{\top}M_i\eta_i+\tfrac12\tilde\theta_i^{\top}\Gamma_i^{-1}\tilde\theta_i+\tfrac{k_{ei}}{2}y_i^{\top}y_i+\tfrac{k_{ei}}{2}e_i^{\top}e_i\)，用 \(\dot M-2C\) 反对称消去 Coriolis 项，得

$$
\dot V_i\le-\gamma_i\|e_{zi}\|^2,\qquad e_{zi}=(\eta_i^{\top},y_i^{\top},e_i^{\top})^{\top}
$$

⇒ \(e_{zi}\in L_2\cap L_\infty\) ⇒ （\(\dot e_{zi}\in L_\infty\) + Barbalat，Lemma 2.3）\(e_{zi}\to0\) ⇒ \(e_i\to0\) 且 \(\Delta_i\to0\) ⇒ 一阶积分器带衰减扰动（Lemma 2.2）⇒ \(z_{i,l}\) 各分量趋于一致 ⇒ \(q_i-q_j\to0,\;\dot q_i\to0\)。

**注意**：结论是**渐近**一致（指数收敛的是参考模型，实际关节只是渐近）。想要"指定时间"就要换 #3879 的增益调度。

## A.3 [OKB #3879]（Shi et al., TIE 2026）：虚拟系统 + TVPLE 时变增益 + 速度估计器

### 第 0 步：结构上它比 #173 多一层"部分量测"的技巧

定义**部分量测状态** \(\bar x_i=[q_i^{\top},x_{i,2}^{\top},\dots,x_{i,n}^{\top}]^{\top}\)：把虚拟系统的第 1 块状态 \(x_{i,1}\) **直接用实测 \(q_i\) 顶替**。于是编队误差

$$
\xi_{\bar x,i}=\sum_{j}a_{ij}\big[(\bar x_i-h_i)-(\bar x_j-h_j)\big]
$$

里出现的全是"可测量 + 虚拟系统解析状态"，**既不需要本机速度，也不需要邻居速度**（一步同时消 C1/C2 的输入侧）。

### 第 1 步：TVPLE 时变增益 ⇒ 预设时间（这是它区别于所有人的地方）

虚拟系统（式 (9a)）：

$$
\dot x_i=A x_i-c_iBB^{\top}Q_t\,\xi_{\bar x,i}+Bv_i
$$

其中 \(Q_t\) 是**时变参数 Riccati 方程**（TVPLE，式 (12)）的解：

$$
A^{\top}Q_t+Q_tA-Q_tBB^{\top}Q_t=-\gamma_1(t)Q_t,\qquad \gamma_1(t)=\frac{\alpha_1}{T_1-t},\;\;\alpha_1>\frac{\bar\delta}{np}
$$

为什么这样就"预设时间"？因为引理 3 给出两条：\(\mathrm{tr}(B^{\top}Q_tB)=\kappa_t=np\gamma_1\)，且 \(\lambda_{\min}(Q_t)\ge\rho\big(\sum_{s=0}^{n-1}\gamma_1^{-(2s+1)}\big)^{-1}\)。于是

$$
\|\xi_x(t)\|^2\le\frac{\chi_1}{\omega_{\min}\bar\delta}\sum_{s=0}^{n-1}\frac{\|\xi_x(0)\|^2}{\gamma_1^{2s+1}(t)}\xrightarrow[t\to T_1]{}0
$$

**收敛时间与初始条件、与增益取值都无关**，只由 \(\gamma_1\) 的极点 \(T_1\) 决定——这是"预设时间"而非"固定时间"的判别标准。

> 实现上不必解 Riccati 迭代：对 \((A+\tfrac{\gamma_1}{2}I)Q_t^{-1}+Q_t^{-1}(A+\tfrac{\gamma_1}{2}I)^{\top}=BB^{\top}\) 解一次**线性** Lyapunov 方程即可得 \(Q_t^{-1}\)（式 (3)），这是可工程化的关键细节。

### 第 2 步：速度估计器——与 #173 的滤波器**同一个骨架**

式 (9c)：

$$
\dot\vartheta_i=-(\mu_{t,i}+1)\vartheta_i+(\mu_{t,i}^2+1+\dot\mu_{t,i})\,(q_i-x_{i,1}),\qquad \vartheta_i(0)=0
$$

取 \(\tilde\vartheta_i=\vartheta_i-\mu_{t,i}e_i\)（\(e_i=q_i-x_{i,1}\)），求导得（式 (26)）：

$$
\dot{\tilde\vartheta}_i=-\tilde\vartheta_i+e_i-\mu_{t,i}\eta_i,\qquad \eta_i=\dot e_i+e_i+\tilde\vartheta_i
$$

把它和 #173 的式 (25)/(24) 并排放：

| | #173 | #3879 |
|---|---|---|
| 滤波状态 | \(y_i\) | \(\tilde\vartheta_i\) |
| 动态 | \(\dot y_i=-y_i+e_i-k_{wi}\eta_i\) | \(\dot{\tilde\vartheta}_i=-\tilde\vartheta_i+e_i-\mu_{t,i}\eta_i\) |
| 合成量 | \(\eta_i=y_i+e_i+\dot e_i\) | \(\eta_i=\tilde\vartheta_i+e_i+\dot e_i\) |
| 常数增益 vs 时变增益 | \(k_{wi}(t)\) 慢时变（只依赖参考轨迹） | \(\mu_{t,i}(t)\) **在 \(T_2\) 处发散**（\(\propto\gamma_{2,i}\)） |

**结构完全相同，唯一差别是增益调度**：把 \(k_{wi}\) 换成在 \(t\to T_2\) 发散到 \(\infty\) 的 \(\mu_{t,i}\)，就把"渐近"升级成"预设时间"。这是两篇最本质的对照。

### 第 3 步：控制律 + 自适应律（自适应律直接写成积分形式）

$$
\tau_i=Y_{x,i}(x_{i,1},\dot x_{i,1},\ddot x_{i,1})\,\hat\theta_i+k_{u,i}\mu_{t,i}\tilde\vartheta_i-k_{u,i}\,(q_i-x_{i,1})
$$

$$
\hat\theta_i(t)=-\Gamma_i\!\int_0^t\!\big[\gamma_{2,i}^2Y_{x,i}^{\top}(\tilde\vartheta_i+e_i)-2\dot\gamma_{2,i}\gamma_{2,i}\dot Y_{x,i}^{\top}e_i\big]\mathrm d\tau-\gamma_{2,i}^2\Gamma_iY_{x,i}^{\top}e_i+\hat\theta_i(0)
$$

三处细节值得记：

1. 回归矩阵 \(Y_{x,i}\)、其导数 \(\dot Y_{x,i}\) 都在**虚拟系统的解析轨迹**上取值（\(x_{i,1},\dot x_{i,1},\ddot x_{i,1}\) 由式 (9a) 内部生成）⇒ 不需要 \(\dot q_i\)。
2. 自适应律里出现的是 \(\tilde\vartheta_i+e_i\) 与 \(e_i\)，**没有 \(\dot e_i\)**——它从一开始就写成积分形式，把 #173 那步"分部积分"内嵌进设计里了。
3. \(\gamma_{2,i}=\alpha_{2,i}/\big(\alpha_{3,i}(T_2-t)\big)\) 与 \(T_2<T_1\) 构成**双时间尺度**：内层跟踪（\(T_2\)）必须先于外层编队（\(T_1\)）完成，否则 \(\Delta_1\) 这个"跟踪误差扰动项"会把虚拟系统的预设时间结论破坏掉（原文 §III-B 的 \(\Delta_1\) 分析就是这个意思）。

### 第 4 步：为什么它也只能"半全局"

定理 1 的措辞是 "for given initial states within a bounded range"。原因很具体：

$$
\mu_{t,i}=\frac{\delta_{1,i}\beta_{2,i}^2}{4k_{m,i}}\eta_{x,i}+\frac{k_{u,i}}{k_{m,i}}+\frac{\delta_{2,i}}{k_{m,i}}\gamma_{2,i},\qquad
k_{u,i}=\beta_{2,i}\sqrt{\kappa_i\eta_{e,i}}+\beta_{1,i}+\frac{3}{\delta_{1,i}}
$$

其中 \(\eta_{e,i}=\tfrac12\gamma_{2,i}^2(0)k_{M,i}\bar{\dot e}_i^2+\tfrac12\bar{\tilde\theta}_i^{\top}\Gamma_i^{-1}\bar{\tilde\theta}_i\) 需要**初始速度误差与初始参数误差的上界**。没有这两个先验界，\(k_{u,i}\) 与吸引域定不出来 ⇒ 只能半全局。

### 第 5 步：设计流程（Algorithm 1，可直接照做）

1. 给定期望 TVF \(h_i=[h_{q,i}^{\top},\dot h_{q,i}^{\top},\dots]^{\top}\)，检验可行性条件 \(\tilde BAh_i-\tilde B\dot h_i=0\)；
2. 算编队补偿 \(v_i=-\hat B(Ah_i-\dot h_i)\)；
3. 选 \(\alpha_1>\bar\delta/(np)\)，解 TVPLE (12) 得 \(Q_t\)；
4. 选 \(\alpha_{2,i}>\max\{k_{M,i},1\},\;0<\alpha_{3,i}\le\delta_{2,i},\;0<T_2<T_1\)，得 \(\gamma_{2,i}\)；
5. 用式 (14)(15) 定 \(\mu_{t,i},k_{u,i}\)（需要初始误差界）。

## A.4 统一模板：两篇是同一骨架的两种参数调度

```
① 参考/虚拟信号 r_i  ← 只用相邻位置差 + 自身解析模型
        （#173: 三阶线性参考模型；#3879: n 阶虚拟系统 + 部分量测状态）
② e_i = q_i - r_i ,  一阶辅助滤波器 s_i ： ṡ_i = -(k+1)s_i + (k²+1+ḱ)e_i
③ 伪速度误差 η_i = ė_i + e_i + s̃_i      （不可测，仅证明用）
④ τ_i = Y(x_ref)θ̂_i + k_u·k·s̃_i - k_u·e_i   （全程只用 q_i）
⑤ θ̂̇_i = -ΓY^Tη_i  →  改写成积分形式（消去 ė_i）
```

- **#173**：\(k=k_{wi}(t)\) 由本地参数界 + 自身参考轨迹决定（**全分布式**）⇒ 渐近收敛。
- **#3879**：\(k=\mu_{t,i}(t)\) 含 \(\gamma_{2,i}=\alpha_{2,i}/(\alpha_3(T_2-t))\) ⇒ 发散增益 ⇒ **预设时间**收敛；代价是 \(T_2\) 前需处理增益爆炸，且 \(c_i\) 的上界含 \(a(L)\)（严格说**不是**全分布式）。

## A.5 逐项对比

| 维度 | [OKB #173] | [OKB #3879] |
|---|---|---|
| 参考信号阶数 | **三阶**线性参考模型（因自适应律需要 jerk，Remark 3.1 明确说二阶不够） | **n 阶**虚拟系统（\(n\ge3\)）+ 部分量测状态 \(\bar x_i\) |
| 速度处理 | 滤波器**隐式替代**速度，不显式给出 \(\hat{\dot q}_i\) | 滤波器 + 辅助变量 \(\tilde\vartheta_i\)，可视为"带时变增益的速度估计" |
| 自适应律 | 微分形式 → 靠**分部积分**改成可实现的积分形式 | 设计时**直接给出积分形式** |
| 增益调度 | \(k_{wi}\) 慢时变，仅依赖自身参数与参考轨迹 | \(\mu_{t,i},\gamma_{2,i}\) 在 \(T_2\) 发散（TVPLE 调度） |

## A.6 复用到"异构 EL + 仅位置 + 合围"时的三个提醒

1. **别照搬 #173 的 \(k_{wi}\) 公式**：\(k_{wi}\) 里含 \(\underline m_i,\zeta_{i,1},\zeta_{i,2},\beta_i\)，这些界在同构时可统一给，异构（\(n_i\) 不同、\(M_i\) 结构不同）时必须**逐智能体**重新界定，并保证 \(\eta_i\) 维数随 \(n_i\) 变化——#173 的 \(\Omega_i\) 证明是按 \(p\) 维固定写的。
2. **合围需要"参考信号来自凸包"**：#173/#3879 的参考信号都由**一致性/编队**生成（\(\sum a_{ij}(q_i-q_j)\) 或 \(h_i\)）。合围要把驱动项换成"到目标的相对位置 + 凸包约束"（对照 [OKB #883] 的柔性 fencing 项；注意该文用了本机测速，移植时须做 §5.1 所述替换），此时 C3 里多出一个**目标速度**，若目标变速则需再加一层目标状态估计器（对照 [OKB #2860] 的分布式相对位置估计器）。
3. **安全约束会破坏 \(\dot V\le0\) 的干净结构**：CBF/BLF 会引入额外的切换或投影（[OKB #1844] 用 proxy + virtual tracking 两个子系统正是为了不让 CBF 直接污染速度跟踪环）。若把 #3879 的发散增益 \(\mu_{t,i}\) 与 CBF 的 QP 直接串联，\(T_2\) 附近的数值刚性会非常严重——这是可预见的实现难点，也是可以写成贡献点的地方。
