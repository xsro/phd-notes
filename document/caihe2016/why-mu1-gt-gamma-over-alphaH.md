# 为什么需要 `μ₁ > γ / α_H`？

> 论文：He Cai, Frank L. Lewis, Guoqiang Hu, Jie Huang,
> *"The adaptive distributed observer approach to the cooperative output regulation of linear multi-agent systems"*, Automatica, 2016.
> 对应本地文件 `3343.md`。

条件 `μ₁ > γ / α_H` 出现在 **Lemma 2(ii)**（`3343.md:174`）与 **Remark 4**（`3343.md:344`）。

---

## 1. 符号定义

- `γ = max(ℜ(σ(S)))`：leader 系统矩阵 `S` 的特征值实部最大值（`3343.md:174`）。
  它衡量 **leader 信号 `v(t) = e^{St} v(0)` 的最大增长率**。若 `γ > 0`，leader 信号是指数增长的（本文借此处理 ramp / 增长型参考信号）。
- `α_H = min(ℜ(σ(H)))`，其中 `H = L + diag(a_{10}, …, a_{N0})`（`3343.md:160`）。
  `H` 由通信图（leader 为根）决定，`α_H` 衡量 **图的连通性 / 谱隙**。在 Assumption 4（生成树 + leader 为根）下，`H` 的所有特征值实部为正，故 `α_H > 0`，除法有意义。
- `μ₁`：自适应估计矩阵 `S` 的耦合增益，见 (5a)
  `Ṡ_i = μ₁ Σ_{j∈N_i} a_{ij} (S_j − S_i)`。

---

## 2. 为什么需要 `μ₁ > γ / α_H`

关键来自 Lemma 2 的两部分。

### 2.1 `Ŝ_i = S_i − S` 的衰减速率（Lemma 2(i)，`3343.md:160`）

(5a) 可写成向量化形式

```
vec(Ṡ) = −μ₁ (I_q ⊗ H ⊗ I_q) vec(Ŝ)
```

于是

```
‖Ŝ_i(t)‖ ≤ β_H ‖Ŝ_i(0)‖ · e^{−μ₁ α_H t}
```

即矩阵估计误差以速率 **`μ₁ · α_H`** 指数衰减。

### 2.2 `η̃` 方程中的交叉项（Lemma 2(ii)，`3343.md:165–174`）

把 `η` 误差动力学 (11) 写成

```
η̃˙ = [(I_N ⊗ S) − μ₂(H ⊗ I_q)] η̃  +  S̃_d η̃  +  S̃_d (1_N ⊗ v)
```

其中扰动项 `S̃_d (1_N ⊗ v)` 的衰减由 `Ŝ` 与 `v` 的乘积决定。由于 `v(t) = e^{St} v(0)`，其范数至多按 `e^{γ t}` 增长；若 `S` 含非半单特征值（本文已去掉"半单"假设），还会多一个多项式因子 `t^{m-1}`，即 `‖v(t)‖ ≤ c·e^{γ t} t^{m-1}`。故

```
‖S̃_d(t) (1_N ⊗ v(t))‖
   ≤ (const) · e^{−μ₁ α_H t} · e^{γ t} · t^{m-1}
   = (const) · t^{m-1} · e^{−(μ₁ α_H − γ) t}
```

只要 `μ₁ α_H > γ`，指数项 `e^{−(μ₁ α_H − γ)t}` 主导多项式因子 `t^{m-1}`，该乘积仍指数衰减到 0。

要让这一项 **指数衰减到 0**（Lemma 1 收敛所必须），需要

```
μ₁ α_H − γ > 0   ⟺   μ₁ > γ / α_H
```

**这就是 `μ₁ > γ / α_H` 的来源**：分布式观测器估计 `S` 的速度，必须 **快于** leader 信号 `v` 的增长速度。否则 `Ŝ` 衰减太慢、`v` 增长太快，乘积 `Ŝ·v` 不衰减（甚至发散），`η̃ → 0` 的证明就断了。

---

## 3. 与之配对的 `μ₂ > γ / α_H`

同一形式也约束 `μ₂`，但原因不同——要使齐次矩阵

```
M = (I_N ⊗ S) − μ₂ (H ⊗ I_q)
```

为 Hurwitz。由于两个 Kronecker 项作用于不同张量腿、彼此可交换，`M` 的特征值实部为

```
ℜ(s_k) − μ₂ ℜ(h_j),    s_k ∈ σ(S),  h_j ∈ σ(H)
```

其中最大的是 `γ − μ₂ α_H`。要 Hurwitz 须

```
γ − μ₂ α_H < 0   ⟺   μ₂ > γ / α_H
```

即：**观测器耦合增益必须足够大，使扩散项 `μ₂ H` 压过 leader 的不稳定项 `S`**。

---

## 4. 直观总结

两个条件本质是同一句话的两个侧面——**耦合增益必须胜过（leader 增长率 / 图连通性）**：

| 增益 | 作用 | 为什么需要 `> γ / α_H` |
|---|---|---|
| `μ₂` | 让 `η` 误差齐次部分 Hurwitz | 扩散项压过 `S` 的不稳定增长 |
| `μ₁` | 让 `S` 估计误差衰减快于 `v` 增长 | 保证交叉项 `Ŝ·v → 0` |

- `α_H` 越大（图越连通）→ 所需增益越小；
- `γ` 越大（leader 信号增长越快）→ 所需增益越大。

---

## 5. 为什么这篇论文必须显式写出它

原文 Cai & Huang (2016) 假设 **`S` 的特征值半单且实部全为 0**，此时 `γ = max ℜ(σ(S)) ≤ 0`，于是 `γ / α_H ≤ 0`，对任何正的 `μ₁, μ₂` 都自动满足——这正是 Lemma 2(i) / Remark 4 中 *"if none of the eigenvalues of S has positive real parts, then … for any positive μ"* 的由来。

本文 **去掉了"实部为 0"的限制** 以处理 ramp / 增长信号（可能 `γ > 0`），下界 `γ / α_H` 才变得非平凡、必须显式选取。Remark 4（`3343.md:344`）还顺势给出对应的 `μ₃` 下界：

```
μ₃ ≥ μ₁ α_H / min σ(Q_iᵀ Q_i)  >  γ / α_H · (α_H / min σ(Q_iᵀ Q_i))
```

（其中 `Q_i` 为 `η_i` 动力学 (3) 的可观测性矩阵，由 Assumption 3 满秩。）

---

## 6. 辅助论证：`M` 的特征值如何得到

`M = I_N ⊗ S − μ₂ H ⊗ I_q`。由于 `(I_N ⊗ S)` 与 `(H ⊗ I_q)` 可交换，它们可同时三角化，`M` 的特征值为两矩阵特征值按作用腿组合：

```
σ(M) = { s_k − μ₂ h_j : s_k ∈ σ(S),  h_j ∈ σ(H) }
```

于是 `M` 实部最大的特征值为 `max_k ℜ(s_k) − μ₂ min_j ℜ(h_j) = γ − μ₂ α_H`，由此直接得到 Hurwitz 条件 `μ₂ > γ / α_H`。

---

## 7. 如何严格保证 `M = (I_N ⊗ S) − μ₂(H ⊗ I_q)` 为 Hurwitz

保证 `M` Hurwitz 的完整逻辑链：

### 7.1 前提：图连通性（根基）

由 **Assumption 4**（含 leader 的有向生成树）及 **Hu & Hong (2007) Lemma 4**，矩阵 `H = L + diag(a_{10}, …, a_{N0})` 的**所有特征值实部为正**，故

```
α_H = min(ℜ(σ(H))) > 0
```

这是整个增益下界能成立的根基：若 leader 不可达（图不连通），则 `α_H ≤ 0`，`γ / α_H` 无定义或为负，结论失效。

### 7.2 关键代数事实：两个 Kronecker 项可交换

`(I_N ⊗ S)` 与 `(H ⊗ I_q)` 作用于不同张量腿，彼此可交换：

```
(I_N ⊗ S)(H ⊗ I_q) = (I_N H) ⊗ (S I_q) = H ⊗ S
(H ⊗ I_q)(I_N ⊗ S) = (H I_N) ⊗ (I_q S) = H ⊗ S
```

因此二者可**同时三角化**，`M` 的特征值（按重数）为两者特征值的逐对相加：

```
σ(M) = { s_k − μ₂ h_j : s_k ∈ σ(S),  h_j ∈ σ(H) }
```

（其中 `σ(I_N ⊗ S) = {s_k}` 每个重复 N 次，`σ(H ⊗ I_q) = {h_j}` 每个重复 q 次。）

### 7.3 Hurwitz 阈值推导

`M` 的特征值实部为 `ℜ(s_k) − μ₂ ℜ(h_j)`，其中最大者为

```
max_k ℜ(s_k) − μ₂ · min_j ℜ(h_j) = γ − μ₂ α_H
```

`M` Hurwitz ⟺ 所有特征值实部 `< 0` ⟺ `γ − μ₂ α_H < 0` ⟺

```
μ₂ > γ / α_H          （由 α_H > 0，除法方向不变）
```

### 7.4 两种情形的统一表述（对应 Lemma 2(ii) 与 Remark 4）

- **`γ ≤ 0`**（`S` 无正实部特征值）：对任意 `μ₂ > 0` 都有 `γ − μ₂ α_H < 0`，故 `M` **自动 Hurwitz**。这正是 Cai & Huang (2016) 的设定（其额外假设 `S` 特征值半单且实部为 0，故 `γ ≤ 0`）。
- **`γ > 0`**（`S` 含 ramp / 增长型模式）：必须**显式取** `μ₂ > γ / α_H`；否则最大特征值实部 `≥ 0`，`M` 非 Hurwitz，`η̃` 的齐次部分不稳定，收敛证明断裂。

### 7.5 职责区分（重要）

`M` 的 Hurwitz **只依赖 `μ₂`**——`μ₁` 根本不出现在 `M` 中。论文 3343.md:174 把 `μ₂ > γ/α_H` 与 `μ₁ > γ/α_H` 并列为联合充分条件，但二者职责不同：

- `μ₂ > γ/α_H` → 让齐次矩阵 `M` Hurwitz；
- `μ₁ > γ/α_H` → 让交叉项 `S̃_d(1_N ⊗ v)` 指数衰减，以满足 Lemma 1 的 `F₂(t) → 0` 条件。

### 7.6 Lyapunov 视角（与 Su & Huang 2012a 一致）

当 `γ ≤ 0` 时，`M` 的 Hurwitz 也可由 `−M` 的 Lyapunov 方程正定解直接得到：其主导块 `I_N ⊗ S` 半稳定、扩散块 `μ₂ H ⊗ I_q` 严格稳定，且二者可交换，标准论断保证 `M` 稳定。而 `γ > 0` 时，特征值论证给出**唯一的显式增益下界** `μ₂ > γ/α_H`，这是本文去掉"零实部"假设后新引入的约束。
