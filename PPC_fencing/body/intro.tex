\section{Introduction}
\label{sec:intro}

Target fencing is a representative cooperative-control problem in which a
group of agents must surround a moving target while maintaining a safe
spatial configuration.  A typical objective is threefold: the target should
belong to the convex hull generated by the agents, inter-agent collisions
must be avoided for all time, and the agents should eventually match the
target velocity.  These requirements couple a global geometric task with
local safety constraints, making fencing a useful benchmark for distributed
multi-agent control.

Most existing fencing protocols are designed to guarantee asymptotic
enclosure.  Such results establish that the target eventually lies in the
agents' convex hull, but the transient behavior is usually determined
indirectly by the initial condition, controller gains, and the interaction
potential.  In applications where the target must be enclosed within a
specified time scale or with a prescribed maximum error, asymptotic
convergence alone is not sufficient.

Prescribed-performance control (PPC) provides a natural way to specify the
allowable evolution of an error signal before the controller is implemented.
By selecting a positive performance function $\rho(t)$, one can encode the
admissible overshoot, convergence rate, and steady-state error bound through
the constraint $\norm{\tilde p(t)}<\rho(t)$, where $\tilde p$ is the
centroid-to-target error.  The main challenge is to impose this soft
performance envelope without destroying the hard collision-avoidance fence
provided by artificial-potential functions.

This note develops a PPC fencing framework for double-integrator agents and
a moving target.  The first design applies PPC directly to the swarm centroid
and superimposes zero-sum local terms for collision avoidance and formation
maintenance.  The second design follows an APF-filtered individual-error
idea: each agent tracks a filtered target-relative error, and the zero-sum
property of the filter converts local PPC guarantees into a centroid PPC
bound.  This second structure avoids differentiating the repulsive APF term,
which is useful when the potential depends on relative positions and active
neighbor sets.

The rest of the note is organized as follows.  Section~\ref{sec:problem}
formulates the fencing problem and recalls the PPC transformation.
Section~\ref{sec:design} gives the centroid-level PPC controller.
Section~\ref{sec:result2} presents the APF-filtered individual PPC

and Section~\ref{sec:conclusion} concludes the note.
