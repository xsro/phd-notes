# Conference paper draft

`paper.tex` is an English, self-contained two-column conference manuscript based on `../fencing-rotation.tex`. The five vector figures of the manuscript live in `figures/` and are regenerated in place by `scripts/make_figures.py`; see below.

Build from this directory:

```sh
latexmk -pdf -interaction=nonstopmode -halt-on-error paper.tex
pdfinfo paper.pdf
```

## Reproducing the figures

`paper.tex` uses two figures, both produced by `scripts/make_figures.py`: `figures/fig-regimes.pdf` (3x3 snapshot summary: rigid rotation, static formation, breathing) and `figures/fig-jamrate.pdf` (log-log gap minus safety distance for the jamming branch). Integrations are cached in `scripts/cache/`, and the stored scans of the source report (`data/alpha/*.csv`, `data/n_scaling_results.json`) are copied once into `data/` in this directory on the first run, so no simulation output has to be duplicated by hand.

From `scripts/`. PyPI is not reachable from this machine, so the commands pass a mirror through `uv`'s default index (drop `--default-index` where `pypi.org` works):

```sh
# all figures of the paper -> ../figures/*.pdf
uv run --no-project --default-index https://mirrors.aliyun.com/pypi/simple \
    --with numpy --with scipy --with matplotlib python make_figures.py all

# a subset, by name as listed in ORDER
uv run --no-project --default-index https://mirrors.aliyun.com/pypi/simple \
    --with numpy --with scipy --with matplotlib python make_figures.py fig-regimes

# ignore the cached integrations and re-solve the ODEs
uv run --no-project --default-index https://mirrors.aliyun.com/pypi/simple \
    --with numpy --with scipy --with matplotlib python make_figures.py all --force
```

The index can also be exported once per shell:

```sh
export UV_DEFAULT_INDEX=https://mirrors.aliyun.com/pypi/simple
uv run --no-project --with numpy --with scipy --with matplotlib python make_figures.py all
```

Runtime is a few seconds when `scripts/cache/*.npz` exists (about 10 s on a cache miss: one LSODA run per case, plus the BDF collinear run). Every run prints the numbers quoted in the text: the angular speeds of each row, the fitted jamming exponent and `c*`.

Figure text uses Times New Roman with STIX math (`fencing_lib.style()`), matching the IEEE two-column body; the PDFs embed subsetted Type 42 fonts. The script also still contains the additional targets of the source report (`fig1d`, `fig2d-rotation`, `fig2d-omega-sweep`, `fig2d-shape-branch`, `fig2d-degenerate`, `fig2d-spectrum`, `fig2d-direction`, `fig2d-breathing`, `fig2d-bistability`, `fig3d-breathing`, `fig-nscaling`, `fig-alpha`, `fig-double`, `fig-jam`, `fig-rotation-methods`); they are not in `ORDER`, so `all` only rebuilds the two figures used here. After regenerating them, rebuild `paper.pdf` as above.

The local TeX installation provides `IEEEconf.cls` (uppercase), an **IEEE Computer Society** proceedings style, not the lowercase `ieeeconf` class commonly distributed by robotics/control conference organizers. This draft uses the installed `IEEEtran` `conference` class for a reliable IEEE two-column build. Before submission, replace the document class and title/author block with the exact `ieeeconf` bundle from the target conference and re-check page limits and PDF layout. Author details are placeholders.

The figures are generated by `scripts/make_figures.py`; see the source report for simulation details. In particular, the numerical spectral evidence is not claimed to be a certified eigenvalue bound. The body cites the original controller and distinguishes proved frequency selection from observed long-term behaviors.
