# 锁定频率的周期规律 — 猜想与分析

## 数据基础

对 N=3 到 35 的 11 组仿真数据，锁定态的频率呈现**两个离散值**：

| N | f_lock (Hz) | T_lock (s) | (f_lock/f_rot)² | C_eff = ω_lock² − k₂ |
|---|------------|------------|-----------------|---------------------|
| 5 | 0.1714 | 5.833 | 2.320 | 0.660 |
| 15 | 0.2000 | 5.000 | 3.158 | 1.079 |
| 20 | 0.2000 | 5.000 | 3.158 | 1.079 |
| 25 | 0.2000 | 5.000 | 3.158 | 1.079 |
| 30 | 0.1714 | 5.833 | 2.320 | 0.660 |
| 35 | 0.2000 | 5.000 | 3.158 | 1.079 |

其中 f_rot = √k₂/(2π) = 0.1125 Hz, k₂ = 0.5。

## 核心观察

### 1. 锁定频率是离散的，不是连续的

尽管 N 从 5 变到 35，锁定频率**只取两个值**：0.171 Hz 和 0.200 Hz。
这说明锁定频率不由 N 直接决定，而是由**吸引子的几何结构**决定。

### 2. 两个锁定频率的平方比

$$\frac{\omega_{\text{lock,2}}^2}{\omega_{\text{lock,1}}^2} = \frac{3.158}{2.320} \approx 1.361$$

这个比值接近：
- 黄金比例 φ = 1.618（不太接近）
- 11/8 = 1.375（较接近）
- 4/3 = 1.333（不太接近）

### 3. 有效刚度比

$$\frac{C_{\text{eff,2}}}{C_{\text{eff,1}}} = \frac{1.079}{0.660} \approx 1.635$$

这个比值**非常接近黄金比例 φ = 1.618**。

## 大胆猜想

### 猜想一：形成对称性分类（formation symmetry classes）

锁定频率由 formation 的**点群对称性**决定，而非由 N 直接决定：

| 对称性类 | f_lock (Hz) | f_lock/f_rot | 典型 N | 可能的几何结构 |
|----------|------------|-------------|--------|--------------|
| Class A | 0.171 | 1.52 | 5, 30 | 低配位数 packing（z≈4-6） |
| Class B | 0.200 | 1.78 | 15, 20, 25, 35 | 高配位数 packing（z≈8-12） |

N=5 和 N=30 共享 Class A，可能因为 N=30 是 N=5 的某种"缩放版本"——
车辆数增加了，但 formation 的拓扑结构（配位数、对称性）相同。

### 猜想二：配位数决定有效刚度

有效刚度 C_eff ∝ z · α'(s_typical)，其中 z 是平均配位数：

- Class A: z ≈ 4-6, C_eff ≈ 0.66
- Class B: z ≈ 8-12, C_eff ≈ 1.08

C_eff 比值 1.635 ≈ φ，可能对应两种 packing 的配位数比值：
- 8/5 = 1.6（接近）
- 12/7 ≈ 1.71（不太接近）

### 猜想三：频率锁定的共振条件

锁定发生时，径向模和切向模通过非线性耦合达到频率共振：
$$\omega_{\text{lock}} = \sqrt{k_2 + \beta \cdot C_{\text{rep}}}$$

其中 β 是耦合系数，取决于 formation 几何：
- Class A: β ≈ 0.5-0.6
- Class B: β ≈ 0.8-1.0

β 的离散性导致了 f_lock 的离散性。

### 猜想四：N 的奇偶性/模模式

观察 N 值：
- Class A: N = 5, 30 → 5 mod 25 = 5, 30 mod 25 = 5
- Class B: N = 15, 20, 25, 35 → 15, 20, 25, 35

Class A 的 N 值相差 25。Class B 的 N 值分布更广。
如果存在周期性，周期可能是 25（即 N 和 N+25 属于同一类）。

## 待验证的预测

1. **N=40, 45, 50, 55, 60**：如果周期为 25，则：
   - N=40 (15+25) → Class B, f_lock = 0.200 Hz
   - N=55 (30+25) → Class A, f_lock = 0.171 Hz
   - N=50 (25+25) → Class B, f_lock = 0.200 Hz

2. **改变 k₁, k₂, d 参数**：如果猜想一正确，则改变参数会改变两个锁定频率的值，
   但仍然只有两个离散值。如果猜想二正确，则 C_eff 比值应保持 ≈ φ。

3. **改变初始条件**：如果 formation 对称性是吸引子决定的，则不同 seed
   应收敛到相同的两个锁定频率之一。

## 物理图像

```
Breathing regime:          Locked regime:

  ○  ○  ○                    ○  ○  ○
   \│/                       \│/
    ○      →                   ○       ← formation geometry
   /│\                       /│\
  ○  ○  ○                    ○  ○  ○

f_rad > f_tan               f_rad = f_tan = f_lock
两个独立频率                一个锁定频率
                           由 formation 对称性决定
```

锁定后的系统不是"频率与参数无关"——而是频率由 formation 的**离散几何状态**决定。
这类似于固体物理中，晶格的振动频率由晶格对称性（空间群）决定，而非仅由原子数决定。
