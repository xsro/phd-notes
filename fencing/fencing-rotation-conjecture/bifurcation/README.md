## 核心发现

### 三个共存的吸引子

在 k₂=0.5, d=5, μ=9, N=5 的参数下，系统存在三个共存的吸引子：

| 分支 | ω_eff/√k₂ | 周期 T (k₁=k₂=0.5) | 振幅 | 典型初始条件 |
|------|:---------:|:------------------:|:----:|------------|
| **高频呼吸极限环** | ≈ 3.5 | 2.5 s | 5-30% | case3.py 反例及扰动 |
| **低频呼吸极限环** | ≈ 1.42 | 6.2 s | 5-10% | 扰动正五边形（pert=2.0） |
| **旋转平衡** | = 1.0 | 8.9 s | 0% | 正五边形 |

### 分岔结构

随着 k₁（阻尼）增大：

1. **k₁ < 0.15**：仅低频分支存在，高频分支未激发
2. **k₁ ≈ 0.15-0.30**：**多吸引子共存区域** — 高频和低频分支同时存在
3. **k₁ ≈ 0.35-0.60**：高频分支主导，ω_eff/√k₂ 从 3.71 缓慢下降到 3.51
4. **k₁_crit ≈ 0.65**：极限环通过鞍结分岔消失，系统收敛到旋转平衡

![Enhanced Bifurcation Diagram](data/bifurcation_diagram_enhanced.png)

**三面板分岔图**（从上到下、从左到右）：

| 面板 | 纵轴 | 核心信息 |
|------|------|----------|
| **周期 T** | Period (s) | 高频分支 T ≈ 2.5 s、低频分支 T ≈ 4.5-6.2 s、旋转平衡 T ≈ 8.9 s |
| **频率比** | ω_eff/√k₂ | 三个分支的频率比平台：高频 ≈ 3.5、低频 ≈ 1.42、旋转平衡 = 1.0 |
| **振幅** | Breathing amplitude | 高频分支振幅 ≈ 5-7%、低频分支振幅 ≈ 5-19%、旋转平衡 = 0 |

> 同一 k₁ 下出现多个标记表示多吸引子共存 —— 详见下方说明。

#### 吸引子盆地扫描结果

对 7 个 k₁ 值 × 4 种初始条件的快速分类：

| k₁ | pent_pert0.5 | pent_pert2.0 | case3_pert0.1 | case3_pert0.5 |
|:---:|:------------:|:------------:|:-------------:|:-------------:|
| 0.10 | 旋转平衡 | 旋转平衡 | 低频 LC | 低频 LC |
| 0.20 | 旋转平衡 | 旋转平衡 | 暂态 | 暂态 |
| 0.30 | 旋转平衡 | 旋转平衡 | 高频 LC | 高频 LC |
| 0.40 | 旋转平衡 | 旋转平衡 | 高频 LC | 高频 LC |
| 0.50 | 旋转平衡 | 旋转平衡 | 高频 LC | 高频 LC |
| 0.60 | 旋转平衡 | 旋转平衡 | 高频 LC | 高频 LC |
| 0.65 | 旋转平衡 | 旋转平衡 | 旋转平衡 | 高频 LC |

**关键发现**：
- 扰动正五边形 IC（pert=0.5, 2.0）在所有 k₁ 下均收敛到旋转平衡
- case3 微扰 IC 在 k₁ ≥ 0.30 时收敛到高频分支
- k₁ = 0.65 是临界点：case3_pert0.1 已消失，但 case3_pert0.5 仍存活
- k₁ = 0.20 附近出现暂态（未收敛），说明此处 basin boundary 复杂

### 高频分支的参数规律

```
ω_eff/√k₂ ≈ 3.78 − 0.81·k₁ + 0.39·k₂
```

对 14 组干净数据的线性拟合，误差 < 1.7%（大多数 < 0.5%）。

### 低频分支的参数规律

低频分支的 ω_eff/√k₂ ≈ 1.42，**与 k₁ 和 k₂ 几乎无关**（变化 < 1%）。
这表明低频呼吸模式更接近刚体旋转。

### 多吸引子共存的关键现象

- case3 IC 在 k₁=0.15, 0.20, 0.25 之间反复跳跃于高低频分支
- IC2（case3_pert0.5）在 k₁=0.6 时从高频跳变到低频
- IC1（case3_pert0.3）在 k₁=0.3 时出现中间分支（ratio=2.36, amp=64%）

### 为什么同一个 k₁ 上会有多个标记？

分岔图中，同一个横坐标（k₁ 值）上出现多个不同形状的标记（如同时有圆和三角），**这不是数据错误，而是物理事实**：

> **系统不是单稳态的。同一个参数下可以存在多个吸引子，最终收敛到哪个取决于初始条件。**

具体来说：

| 同一 k₁ 下的标记组合 | 含义 |
|---------------------|------|
| 圆 + 三角 | case3 IC → 高频极限环；正五边形 IC → 旋转平衡（两者共存） |
| 方 + 三角 | 扰动正五边形 IC → 低频极限环；正五边形 IC → 旋转平衡（两者共存） |
| 圆 + 方 | case3 IC → 高频分支；扰动正五边形 IC → 低频分支（两者共存） |

**举例**：在 k₁ = 0.50 处：
- 实心圆 ●：case3 初始条件收敛到高频呼吸极限环（T = 2.485 s）
- 空心三角 ▽：正五边形初始条件收敛到旋转平衡（T = 8.886 s）
- 两者在同一个 k₁ 下同时存在，说明系统是**多稳态**的

这种多吸引子共存正是分岔图的核心科学发现——它表明围捕系统的长期行为不仅由参数决定，还依赖于初始条件。

## 运行

### 生成分岔图（基础版）

```bash
cd bifurcation
python3 simulation/plot_bifurcation.py
```

### 生成分岔图（增强版：三面板 + 吸引子盆地扫描）

```bash
python3 simulation/plot_bifurcation_enhanced.py
```

输出（自动保存到 `data/`）：
- `data/bifurcation_diagram_enhanced.png` — 三面板分岔图（周期、频率比、振幅）
- 控制台输出吸引子盆地分类结果（7 k₁ × 4 IC）

### 径向-切向周期分析

```bash
python3 simulation/radial_tangential_analysis.py
```

输出：每个 agent 的径向周期 T_rad_i、切向周期 T_tan_i、旋转周期 T_rot_i，
以及集体量的周期对照。

## 数据说明

### 图中标记含义

| 标记 | 形状 | 含义 |
|------|:----:|------|
| 实心圆 ● | filled circle | 高频分支权威数据（LSODA, 600s, rtol=1e-6） |
| 空心圆 ○ | hollow circle | 高频分支快速验证（BDF, 120s, rtol=1e-4） |
| 实心方 ■ | filled square | 低频分支权威数据 |
| 空心方 □ | hollow square | 低频分支快速验证 |
| 实心三角 ▼ | filled triangle | 旋转平衡数据 |
| 空心三角 ▽ | hollow triangle | 旋转平衡验证 |
| 叉号 × | cross | 暂态/未收敛 |

> **实心 = 权威数据**（长时高精度积分），**空心 = 快速验证**（短时低精度，仅验证分支存在）。

### 物理参数

| 参数 | 默认值 | 说明 |
|------|:------:|------|
| k₁ | 0.5 | 阻尼系数 |
| k₂ | 0.5 | 约束刚度 |
| d | 5.0 | 碰撞距离 |
| μ | 9.0 | 感知范围 |
| N | 5 | agent 数量 |
