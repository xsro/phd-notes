# 三分法猜想：数值仿真与周期分析

## 项目概述

本项目通过数值仿真验证"三分法猜想"（Trichotomy Conjecture）：

> 围捕闭环系统的长期行为必定属于以下三类之一：
>
> **(A) 旋转平衡轨道** —— 非退化刚体旋转，角速度 |ω| = √k₂，距离收敛到常数
>
> **(B) 卡死边界** —— 至少一对间距趋于碰撞距离 d，位置收敛，观测器发散
>
> **(C) 呼吸极限环** —— 形状变量的非平凡周期轨道，距离周期性振荡不收敛

---

#### 参数规律：ω_eff/√k₂ 的线性拟合

对 14 组干净数据做线性最小二乘拟合：

```
ω_eff/√k₂ ≈ 3.78 − 0.81·k₁ + 0.39·k₂
```

| 参数 | 系数 | 物理含义 |
|------|:----:|----------|
| 常数项 | 3.78 | 基准频率比（k₁,k₂ → 0）|
| k₁ 系数 | −0.81 | 阻尼增大 → 频率比**减小** |
| k₂ 系数 | +0.39 | 约束增大 → 频率比**增大** |

**拟合精度**：误差 < 1.7%（大多数 < 0.5%）

**验证**：

|:--:|:--:|:--------:|:------:|:----:|
| 0.5 | 0.5 | 3.57 | 3.58 | −0.1% |
| 0.5 | 0.3 | 3.49 | 3.50 | −0.2% |
| 0.5 | 0.1 | 3.41 | 3.36 | +1.7% |
| 0.4 | 0.5 | 3.65 | 3.66 | −0.2% |
| 0.6 | 0.5 | 3.49 | 3.51 | −0.5% |
| 0.3 | 0.3 | 3.65 | 3.69 | −0.8% |
| 0.6 | 0.3 | 3.41 | 3.44 | −0.8% |

#### 等价形式

```
ω_eff² ≈ k₂ × (3.78 − 0.81·k₁ + 0.39·k₂)²
```

或近似为：

```
ω_eff² ≈ 12.8·k₂ − 3.2·k₁·k₂ + 1.5·k₂²
```

#### 对称情况 k₁ = k₂

当 k₁ = k₂ 时，公式简化为：

```
ω_eff/√k₂ ≈ 3.78 − 0.81·k + 0.39·k = 3.78 − 0.42·k
```

对 k = 0.5：ω_eff/√k₂ ≈ 3.78 − 0.21 = 3.57（与观测 3.58 一致）

#### 对 k₁ = 0.5 固定

```
ω_eff/√k₂ ≈ 3.38 + 0.39·k₂
```

即 ω_eff² ≈ k₂ × (3.38 + 0.39·k₂)² ≈ 11.4·k₂ + 2.6·k₂² + 0.15·k₂³

主导项：ω_eff² ≈ 11.4·k₂（对小 k₂）；当 k₂ 增大时，k₂² 修正项变得重要。

|:--:|:--:|:---------:|:--------------:|
| 0.3 | 0.3 | 0.62 | 6.13 |
| 0.4 | 0.3 | 0.44 | 8.02 |
| 0.5 | 0.3 | 0.32 | 10.49 |
| 0.6 | 0.3 | 0.24 | 13.82 |
| 0.4 | 0.5 | 0.47 | 13.08 |

> **结论**：(ω_eff²−k₂)/gap 不是常数，说明间隙不能单独决定频率。k₁ 和 k₂ 通过独立机制影响频率：k₁ 主要通过控制振幅和间隙来影响频率，k₂ 则直接通过约束力平衡贡献到 ω_eff²。

## 物理机制：为什么 3.5 倍？

### 核心机制：k₁ 和 k₂ 共同决定频率

```
k₂ 大 → 约束力强 → 直接贡献到 ω_eff² (正效应)
k₁ 大 → 阻尼强 → 振幅小 → 间隙小 → 排斥力梯度陡 → ω_eff 高
       但同时 k₁ 大也抑制呼吸模式 → 极限环减弱 → 频率下降 (负效应)
```

正负效应的竞争产生了 ω_eff/√k₂ 随 k₁ 增大而缓慢下降的规律。

### 对称情况 k₁ = k₂ 的简洁公式

```
ω_eff ≈ 3.55 × √k₂
T ≈ 2π / (3.55 × √k₂) ≈ 1.77 / √k₂
```

**验证**：对 k₁ = k₂ ≥ 0.2，公式误差 < 5%。

### 一般情况的 2D 参数规律（核心发现）

对 14 组干净数据的线性拟合：

```
ω_eff/√k₂ ≈ 3.78 − 0.81·k₁ + 0.39·k₂
```

| 参数 | 系数 | 物理含义 |
|------|:----:|----------|
| 常数项 | 3.78 | 基准频率比 |
| k₁ 系数 | −0.81 | 阻尼增大 → 频率比**减小**（抑制呼吸模式）|
| k₂ 系数 | +0.39 | 约束增大 → 频率比**增大**（直接约束力贡献）|

**拟合精度**：误差 < 1.7%（大多数 < 0.5%）。

### 线性化理论 vs. 观测

如果对呼吸模式在平衡点做线性化，得到的频率远高于观测值：

| k₁ | ω_eff² (观测) | ω_eff² (线性化) | 偏差原因 |
|----|--------------|----------------|----------|
| 0.35 | 6.87 | 5.05 | 线性化低估（靠近平衡点） |
| 0.50 | 6.39 | 11.75 | 线性化高估 |
| 0.60 | 6.15 | 21.01 | 线性化严重高估 |

线性化在 k₁ = 0.35 时低估频率（因为线性化在间隙较大时精度尚可），但在 k₁ ≥ 0.45 时严重高估（因为间隙变小时刚度急剧增大，但振荡导致系统在高刚度区域停留时间极短）。

### 间隙-频率关系

| k₁ | k₂ | 间隙 s₁-d | ω_eff² − k₂ | C·(s₁-d) | 备注 |
|:--:|:--:|:---------:|:-----------:|:--------:|:----:|
| 0.35 | 0.5 | 0.551 | 6.37 | 3.51 | 大间隙 |
| 0.50 | 0.5 | 0.351 | 5.89 | 2.06 | 中间隙 |
| 0.60 | 0.5 | 0.260 | 5.65 | 1.47 | 小间隙 |
| 0.5 | 0.1 | 0.281 | 1.05 | 0.29 | 弱约束 |
| 0.5 | 0.5 | 0.351 | 5.89 | 2.06 | 中约束 |
| 0.5 | 0.7 | 0.372 | 8.51 | 3.17 | 强约束 |

**结论**：C = ω_eff² − k₂ 与间隙没有简单的反比或反平方关系。C·(s₁-d) 不是常数，说明间隙不是唯一决定因素。k₂ 本身也通过约束力平衡直接贡献到 ω_eff²。

### 极限环消失条件

当 k₁ 超过临界值 k₁_crit ≈ 0.65（k₂=0.5 时），阻尼完全压制了呼吸模式：

```
k₁_crit(k₂=0.5) ≈ 0.65
```

在 k₁ = k₁_crit 处，极限环通过鞍结分岔消失，系统收敛到旋转平衡轨道。

## 角速度变化与呼吸周期的关系

### 核心发现：两者是同一物理现象

对**所有 6 个案例**（Case A/B/C + 3 个替代 IC）的验证：

| 案例 | T_breathing (s) | T_om (s) | T_om / T_breathing |
|------|:---------------:|:--------:|:------------------:|
| Case A（旋转平衡） | 6.271 | 6.273 | 1.0003 |
| Case B（卡死边界） | 6.229 | 6.229 | 1.0000 |
| Case C（呼吸极限环） | 2.486 | 2.485 | 0.9994 |
| Alt1（case3_pert0.3） | 2.486 | 2.486 | 1.0000 |
| Alt2（case3_pert0.5） | 2.487 | 2.486 | 0.9994 |
| Alt3（pentagon_pert2.0） | 6.250 | 6.200 | 0.9920 |

> **所有案例均确认：T_breathing = T_om，比值偏差 < 0.8%。**

### 角速度变化周期的初值表达式

agent i 的角速度定义为：

```
ω_i(t) = (r_i × v_i) / |r_i|²
```

平均角速度：

```
ω_mean(t) = (1/N) Σ ω_i(t)
```

总角动量：
```
L(t) = Σ (r_i × v_i) = Σ |r_i|² ω_i
```

在极限环上，L 近似守恒（涨落 < 1.5%），因此：

```
ω_mean(t) ≈ L / (N · r(t)²)
```

其中 r(t) 是平均半径（呼吸模式）。由于 r(t) 以周期 T_breathing 振荡，ω_mean(t) 也以**同一周期**振荡。这就是 T_breathing = T_om 的数学原因。

### 角动量不守恒：初值不能直接决定周期

**关键发现**：总角动量 L **不守恒**！

| 案例 | L₀（初值） | L_final（极限环） | 变化 |
|------|:---------:|:----------------:|:----:|
| Case A | 127.3 | 70.5 | −44.6% |
| Case B | 0.0 | −75.4 | 符号翻转 |
| Case C | 48.3 | −58.7 | **+221.6%** |
| Alt1 | 60.1 | −58.7 | +197.8% |
| Alt2 | 49.9 | −58.7 | +217.8% |
| Alt3 | 210.7 | 75.4 | −64.2% |

> **原因**：k₁ 耦合项 k₁(r_avg − r_i) 不是中心力，产生力矩。系统通过暂态过程"选择"一个特定的 L_final。

### 极限环的特征角动量（按分支）

| 分支 | L_final | ω_mean/√k₂ | T_breathing (s) |
|------|:-------:|:----------:|:---------------:|
| **高频分支**（Case C, Alt1, Alt2） | −58.72 ± 0.01 | −1.095 ± 0.001 | 2.486 ± 0.001 |
| **低频分支**（Case A, Alt3） | 70–75 | +1.000 | 6.25 ± 0.02 |
| **卡死边界**（Case B） | −75.4 | −1.000 | 6.23 |

> **关键结论**：L_final 由**吸引子分支**决定，不是初值的函数。同一分支内所有初值收敛到相同的 L_final 和 T_breathing。

### 呼吸周期的初值表达式（理论）

虽然 L₀ 不能直接决定 T，但可以通过有效势能框架表达：

```
V_eff(r) = ½ k₂ r² + V_rep(r) + L²/(2r²)
```

平衡半径 r_eq 满足：k₂ r − F_rep(r) − L²/r³ = 0

呼吸频率：ω_eff = √(V_eff''(r_eq))

但 L 不是 L₀，而是极限环的特征角动量 L_final，它由系统参数和吸引子分支决定。因此：

```
T_breathing = f(k₁, k₂, d, μ, N, branch)
```

其中 branch ∈ {高频, 低频, 卡死} 由初值所属的吸引子盆地决定。

### 实用表达式

对于**高频分支**（case3.py 及其扰动）：

```
ω_eff/√k₂ ≈ 3.78 − 0.81·k₁ + 0.39·k₂
T_breathing ≈ 2π / (√k₂ · (3.78 − 0.81·k₁ + 0.39·k₂))
```

对于**低频分支**（正五边形及其大扰动）：

```
ω_eff/√k₂ ≈ 1.42
T_breathing ≈ 2π / (1.42 · √k₂) ≈ 4.42 / √k₂
```

### 集群中心向量 a = (1/N) Σ x_i − x_0 的幅角分析

对于**所有 6 个案例**，集群中心 r_cm 都在原点（到机器精度）：

| 案例 | |r_cm|/r | 说明 |
|------|:-------:|------|
| Case A（旋转平衡） | 0.00% | 正五边形 → 质心在原点 |
| Case B（卡死边界） | 0.00% | 质心在原点 |
| Case C（呼吸极限环） | 0.00% | 质心在原点 |
| Alt1（case3_pert0.3） | 0.00% | 质心在原点 |
| Alt2（case3_pert0.5） | 0.00% | 质心在原点 |
| Alt3（pentagon_pert2.0） | 0.00% | 质心在原点 |

> **结论**：a = r_cm ≈ 0，其幅角退化（无定义）。**呼吸周期与向量 a 的幅角变化周期无关。**

### agent 个体角速度变化周期 vs 呼吸周期

对每个 agent 的位置向量 a_i = x_i − x_0 = x_i（目标在原点），其角速度 ω_i(t) 的变化周期与呼吸周期有关，但依赖于 agent 个体：

| Agent | 平均半径 | 半径标准差 | T_om_i / T_breathing | 物理原因 |
|:-----:|:--------:|:---------:|:-------------------:|---------|
| 1 | 4.08 | 1.86 (45%) | **2.0** | 大幅振荡 → 1/r² 基频减半 |
| 2 | 4.09 | 1.86 (45%) | **2.0** | 大幅振荡 → 1/r² 基频减半 |
| 3 | 5.17 | 0.38 (7.3%) | **1.0** | 小幅振荡 → 线性近似 |
| 4 | 5.24 | 0.39 (7.4%) | **1.0** | 小幅振荡 → 线性近似 |
| 5 | 4.17 | 0.26 (6.2%) | **0.5** | 极小振荡 → 高阶谐波主导 |

> **机制**：ω_i = L_i / r_i²。当半径大幅振荡时，1/r² 的非线性产生谐波。不同 agent 的径向振荡幅度不同，导致其角速度的变化周期不同。但**集体平均角速度** ω_mean(t) 的变化周期始终等于呼吸周期。

### 小结

```
− 集体平均角速度 ω_mean(t) 的变化周期 = T_breathing
− 单个 agent 角速度 ω_i(t) 的变化周期 ∈ {T_breathing/2, T_breathing, 2×T_breathing}
− 集群中心向量 a = r_cm ≈ 0，幅角退化，与呼吸周期无关
```

### 与 2D 阻尼振荡器的结构类比

简单 2D 阻尼振荡器

```
ẍ + k₁ẋ + k₂x = 0,  x ∈ ℝ²
```

的解析解给出了角速度的精确表达式：

```
θ(t) = atan2(x₂, x₁)

dot_θ(t) = (x₁v₂ − x₂v₁) / (x₁² + x₂²)
         = R₁R₂·ω·sin(φ₂−φ₁) / [R₁²cos²(ωt−φ₁) + R₂²cos²(ωt−φ₂)]
```

其中 ω = √(4k₂ − k₁²)/2。分母的 cos² 项使 dot_θ 以周期 T = π/ω 振荡：

```
T_dot_θ = π/ω = 2π/√(4k₂ − k₁²)
```

**数值验证**（k₁=k₂=1, x(0)=(1,0), ẋ(0)=(0,1)）：

| 量 | 理论值 | 数值观测 |
|----|:------:|:--------:|
| ω = √(4k₂−k₁²)/2 | 0.8660 | — |
| T_dot_θ = π/ω | 3.6276 s | 3.6275 s |

#### 与围捕系统的对比

| 系统 | T_dot_θ 公式 | T_r² / T_dot_θ |
|------|:-----------:|:--------------:|
| 2D 阻尼振荡器 | T = 2π/√(4k₂ − k₁²) | **1.000**（结构相同）|
| 围捕高频分支 | T = 2π/(3.58√k₂) | **1.000**（结构相同）|

两种系统的 dot_θ 变化周期都等于 r² 的振荡周期，因为：

```
dot_θ = L / r²   （角动量守恒 → 角速度与 r² 反比）
```

当 r² 以周期 T_osc 振荡时，dot_θ 也以同一周期振荡。

#### 关键区别：有效刚度

围捕系统的呼吸周期比用简单公式直接代入的值小得多：

| k₁ | k₂ | 简单公式 T = 2π/√(4k₂−k₁²) | 观测 T_breathing | 比值 |
|:--:|:--:|:------------------------:|:----------------:|:----:|
| 0.5 | 0.5 | 4.750 s | 2.486 s | 0.52 |

因为排斥力增加了系统的有效刚度。将排斥力视为对 k₂ 的修正：

```
ω_eff² ≈ 12.8·k₂  （从 2D 扫描拟合）
k₂_eff = (ω_eff² + k₁²/4) / 4 ≈ 1.616  （k₁=k₂=0.5 时）
T_pred = 2π/√(4·k₂_eff − k₁²) ≈ 2.521 s
```

| 量 | 值 | 误差 |
|----|:---:|:----:|
| 观测呼吸周期 | 2.486 s | — |
| 用 k₂_eff 预测 | 2.521 s | **1.4%** |

> **核心结论**：围捕系统的呼吸周期与简单 2D 振荡器的 dot_θ 变化周期有相同的数学结构。区别在于围捕系统有非线性排斥力，它通过有效刚度 k₂_eff = k₂ + k_rep 来修正周期公式：
>
> ```
> T_breathing = 2π / √(4·k₂_eff − k₁²)
> ```
>
> 其中 k_rep 是排斥力对有效势能曲率的贡献。

## 双稳态与多吸引子结构

### 两个呼吸分支

通过测试不同的初始条件，发现了**两个共存的呼吸极限环分支**：

| 分支 | ω_eff/√k₂ | 周期 T (k₁=k₂=0.5) | 振幅 | 典型初始条件 |
|------|:---------:|:------------------:|:----:|------------|
| **高频分支** | ≈ 3.5 | 2.5 s | 5-30% | case3.py 反例及扰动 |
| **低频分支** | ≈ 1.42 | 6.2 s | 5-10% | 扰动正五边形（pert=2.0）|

### 低频分支的参数规律

对低频分支（IC3：扰动正五边形，seed=99，pert=2.0）：

| k₁ | k₂ | T (s) | ω_eff/√k₂ | 振幅 |
|:--:|:--:|:-----:|:----------:|:----:|
| 0.5 | 0.3 | 8.09 | 1.42 | 9.7% |
| 0.5 | 0.5 | 6.24 | 1.42 | 5.6% |
| 0.5 | 0.7 | 5.25 | 1.43 | 4.8% |
| 0.6 | 0.5 | 6.26 | 1.42 | 6.2% |

> **关键发现**：低频分支的 ω_eff/√k₂ ≈ 1.42，**与 k₁ 和 k₂ 几乎无关**（变化 < 1%）。这与高频分支的行为截然不同。

### 高频分支的参数规律（三个 IC 的对比）

| IC | k₁ | k₂ | T (s) | ω_eff/√k₂ | 振幅 | 公式误差 |
|----|:--:|:--:|:-----:|:----------:|:----:|:--------:|
| IC1 (pert0.3) | 0.5 | 0.5 | 2.56 | 3.47 | 27% | +4.4% |
| IC1 (pert0.3) | 0.4 | 0.5 | — | 3.50 | — | +4.4% |
| IC1 (pert0.3) | 0.6 | 0.5 | 2.57 | 3.46 | 22% | +0.9% |
| IC2 (pert0.5) | 0.5 | 0.5 | 2.54 | 3.49 | 16% | +1.7% |
| IC2 (pert0.5) | 0.4 | 0.5 | — | 3.59 | — | +1.7% |
| IC2 (pert0.5) | 0.6 | 0.5 | 6.28 | 1.42 | 18% | 跳变到低频 |

> **关键发现**：高频分支的 ω_eff/√k₂ ≈ 3.5，与 2D 扫描结果一致。公式 ratio = 3.78 − 0.81·k₁ + 0.39·k₂ 对高频分支误差 < 5%。

### 多吸引子共存

系统存在**三个共存的吸引子**：

1. **旋转平衡**：刚体旋转，无呼吸（正五边形初始条件 → 此）
2. **高频呼吸极限环**：ω_eff/√k₂ ≈ 3.5（case3.py 反例及扰动 → 此）
3. **低频呼吸极限环**：ω_eff/√k₂ ≈ 1.42（大扰动正五边形 → 此）

**关键现象**：
- IC2（case3_pert0.5）在 k₁=0.6 时从高频分支**跳变**到低频分支（T 从 2.5s 跃迁到 6.3s）
- IC1（case3_pert0.3）在 k₁=0.3 时出现**中间分支**（ratio=2.36，amp=64%）
- 同一初始条件在不同参数下可能收敛到不同分支，表明存在复杂的吸引子盆地结构

### 物理含义

低频分支的 ω_eff/√k₂ ≈ 1.42 接近自然旋转频率（ratio=1），表明低频呼吸模式更接近刚体旋转。高频分支的 ratio ≈ 3.5 表明呼吸振荡的频率远高于约束力平衡频率。

两个分支的共存意味着系统在呼吸模式上存在**两种不同的振荡机制**：
- 高频分支：由约束力和排斥力之间的快速平衡驱动
- 低频分支：由系统的整体惯性主导，接近自然旋转频率
