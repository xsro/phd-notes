# 呼吸极限环：案例与分析

## 概述

**呼吸极限环**（Breathing Limit Cycle）是围捕闭环系统长期行为的三类之一（Case C）：

> 形状变量的非平凡周期轨道，距离周期性振荡不收敛。

与旋转平衡（Case A）和卡死边界（Case B）不同，呼吸极限环中 agent 的距离持续周期性振荡，系统 never 收敛到固定半径。

## 物理机制

### 核心机制：k₁ 和 k₂ 共同决定频率

```
k₂ 大 → 约束力强 → 直接贡献到 ω_eff² (正效应)
k₁ 大 → 阻尼强 → 振幅小 → 间隙小 → 排斥力梯度陡 → ω_eff 高
       但同时 k₁ 大也抑制呼吸模式 → 极限环减弱 → 频率下降 (负效应)
```

正负效应的竞争产生了 ω_eff/√k₂ 随 k₁ 增大而缓慢下降的规律。

### 对称情况 k₁ = k₂ 的简洁公式

```
ω_eff ≈ 3.55 × √k₂
T ≈ 2π / (3.55 × √k₂) ≈ 1.77 / √k₂
```

**验证**：对 k₁ = k₂ ≥ 0.2，公式误差 < 5%。

### 一般情况的 2D 参数规律（核心发现）

对 14 组干净数据的线性拟合：

```
ω_eff/√k₂ ≈ 3.78 − 0.81·k₁ + 0.39·k₂
```

| 参数 | 系数 | 物理含义 |
|------|:----:|----------|
| 常数项 | 3.78 | 基准频率比 |
| k₁ 系数 | −0.81 | 阻尼增大 → 频率比**减小**（抑制呼吸模式）|
| k₂ 系数 | +0.39 | 约束增大 → 频率比**增大**（直接约束力贡献）|

**拟合精度**：误差 < 1.7%（大多数 < 0.5%）。

### 线性化理论 vs. 观测

如果对呼吸模式在平衡点做线性化，得到的频率远高于观测值：

| k₁ | ω_eff² (观测) | ω_eff² (线性化) | 偏差原因 |
|----|--------------|----------------|----------|
| 0.35 | 6.87 | 5.05 | 线性化低估（靠近平衡点） |
| 0.50 | 6.39 | 11.75 | 线性化高估 |
| 0.60 | 6.15 | 21.01 | 线性化严重高估 |

线性化在 k₁ = 0.35 时低估频率（因为线性化在间隙较大时精度尚可），但在 k₁ ≥ 0.45 时严重高估（因为间隙变小时刚度急剧增大，但振荡导致系统在高刚度区域停留时间极短）。

### 间隙-频率关系

| k₁ | k₂ | 间隙 s₁-d | ω_eff² − k₂ | C·(s₁-d) | 备注 |
|:--:|:--:|:---------:|:-----------:|:--------:|:----:|
| 0.35 | 0.5 | 0.551 | 6.37 | 3.51 | 大间隙 |
| 0.50 | 0.5 | 0.351 | 5.89 | 2.06 | 中间隙 |
| 0.60 | 0.5 | 0.260 | 5.65 | 1.47 | 小间隙 |
| 0.5 | 0.1 | 0.281 | 1.05 | 0.29 | 弱约束 |
| 0.5 | 0.5 | 0.351 | 5.89 | 2.06 | 中约束 |
| 0.5 | 0.7 | 0.372 | 8.51 | 3.17 | 强约束 |

**结论**：C = ω_eff² − k₂ 与间隙没有简单的反比或反平方关系。C·(s₁-d) 不是常数，说明间隙不是唯一决定因素。k₂ 本身也通过约束力平衡直接贡献到 ω_eff²。

### 极限环消失条件

当 k₁ 超过临界值 k₁_crit ≈ 0.65（k₂=0.5 时），阻尼完全压制了呼吸模式：

```
k₁_crit(k₂=0.5) ≈ 0.65
```

在 k₁ = k₁_crit 处，极限环通过鞍结分岔消失，系统收敛到旋转平衡轨道。

## 角速度变化与呼吸周期的关系

### 核心发现：两者是同一物理现象

agent i 的角速度定义为：

```
ω_i(t) = (r_i × v_i) / |r_i|²
```

平均角速度：

```
ω_mean(t) = (1/N) Σ ω_i(t)
```

总角动量：
```
L(t) = Σ (r_i × v_i) = Σ |r_i|² ω_i
```

在极限环上，L 近似守恒（涨落 < 1.5%），因此：

```
ω_mean(t) ≈ L / (N · r(t)²)
```

其中 r(t) 是平均半径（呼吸模式）。由于 r(t) 以周期 T_breathing 振荡，ω_mean(t) 也以**同一周期**振荡。这就是 T_breathing = T_ω 的数学原因。

### 角动量不守恒：初值不能直接决定周期

**关键发现**：总角动量 L **不守恒**！

| 案例 | L₀（初值） | L_final（极限环） | 变化 |
|------|:---------:|:----------------:|:----:|
| Case A | 127.3 | 70.5 | −44.6% |
| Case B | 0.0 | −75.4 | 符号翻转 |
| Case C | 48.3 | −58.7 | **+221.6%** |
| Alt1 | 60.1 | −58.7 | +197.8% |
| Alt2 | 49.9 | −58.7 | +217.8% |
| Alt3 | 210.7 | 75.4 | −64.2% |

> **原因**：k₁ 耦合项 k₁(r_avg − r_i) 不是中心力，产生力矩。系统通过暂态过程"选择"一个特定的 L_final。

### 极限环的特征角动量（按分支）

| 分支 | L_final | ω_mean/√k₂ | T_breathing (s) |
|------|:-------:|:----------:|:---------------:|
| **高频分支**（Case C, Alt1, Alt2） | −58.72 ± 0.01 | −1.095 ± 0.001 | 2.486 ± 0.001 |
| **低频分支**（Case A, Alt3） | 70–75 | +1.000 | 6.25 ± 0.02 |
| **卡死边界**（Case B） | −75.4 | −1.000 | 6.23 |

> **关键结论**：L_final 由**吸引子分支**决定，不是初值的函数。同一分支内所有初值收敛到相同的 L_final 和 T_breathing。

### 呼吸周期的初值表达式（理论）

虽然 L₀ 不能直接决定 T，但可以通过有效势能框架表达：

```
V_eff(r) = ½ k₂ r² + V_rep(r) + L²/(2r²)
```

平衡半径 r_eq 满足：k₂ r − F_rep(r) − L²/r³ = 0

呼吸频率：ω_eff = √(V_eff''(r_eq))

但 L 不是 L₀，而是极限环的特征角动量 L_final，它由系统参数和吸引子分支决定。因此：

```
T_breathing = f(k₁, k₂, d, μ, N, branch)
```

其中 branch ∈ {高频, 低频, 卡死} 由初值所属的吸引子盆地决定。

### 实用表达式

对于**高频分支**（case3.py 及其扰动）：

```
ω_eff/√k₂ ≈ 3.78 − 0.81·k₁ + 0.39·k₂
T_breathing ≈ 2π / (√k₂ · (3.78 − 0.81·k₁ + 0.39·k₂))
```

对于**低频分支**（正五边形及其大扰动）：

```
ω_eff/√k₂ ≈ 1.42
T_breathing ≈ 2π / (1.42 · √k₂) ≈ 4.42 / √k₂
```

## 径向周期与切向周期的分离分析

### 概念定义

在呼吸极限环中，agent 的运动可以分解为两个独立的周期性分量：

| 量 | 符号 | 定义 | 物理含义 |
|----|:----:|------|----------|
| **径向距离** | r_i(t) | \|x_i(t)\| | agent 到目标的距离 |
| **径向周期** | T_rad_i | r_i(t) 振荡的周期 | 径向呼吸的快慢 |
| **角位置** | θ_i(t) | atan2(y_i, x_i) | agent 的方位角 |
| **角速度** | ω_i(t) | dθ_i/dt = (x_i×v_i)/r_i² | agent 绕目标旋转的快慢 |
| **切向周期** | T_tan_i | ω_i(t) 变化的周期 | 角速度振荡的快慢 |
| **旋转周期** | T_rot_i | θ_i(t) 增加 2π 所需时间 | agent 绕目标转一圈的时间 |

> **关键区分**：
> - **切向周期** T_tan 是角速度**振荡**的周期（ω_i 回到相同值的时间）
> - **旋转周期** T_rot 是角位置**旋转一圈**的时间（θ_i 增加 2π 的时间）
> - 两者完全不同：T_rot ≈ 9.1 s（转得慢），T_tan ≈ 1.2-5.0 s（振荡得快）

### 核心发现：集体与个体的分离

**集体量**（平均半径、平均角速度）的径向周期和切向周期**严格相等**：

```
T_rad_mean = T_tan_mean = T_breathing
```

**个体量**的径向周期和切向周期**可以不同**，且不一定等于 T_breathing。

这是呼吸极限环的本质特征：系统存在一个单一的特征周期 T_breathing， governs 集体行为的径向和切向振荡，但个体 agent 由于非线性效应和角动量非守恒，表现出不同的周期。

### 个体周期偏离的物理机制

#### 基本关系

对每个 agent i，角速度与半径的关系为：

```
ω_i(t) = L_i(t) / r_i(t)²
```

其中 L_i = x_i × v_i 是 agent i 的角动量。

**如果 L_i 严格守恒**，则 ω_i ∝ 1/r_i²，那么 T_tan_i = T_rad_i（因为 1/r_i² 的振荡周期等于 r_i 的振荡周期）。

**但 L_i 不守恒**！k₁ 耦合项 k₁(r_avg − r_i) 不是中心力，产生力矩：

```
dL_i/dt = τ_i = k₁(r_avg − r_i) × (x_i − x_cm)
```

因此 T_tan_i 与 T_rad_i 之间的关系被打破。

#### 三种典型行为

| 振幅类型 | Agent | T_rad/T_breath | T_tan/T_breath | 机制 |
|---------|:-----:|:-------------:|:-------------:|------|
| **大幅振荡** (>40%) | 1, 2 | 2.0 | 2.0 | 半径在两个极值之间缓慢振荡，1/r² 基频减半。L_i 的变化恰好补偿了非线性，使 T_tan = T_rad = 2T_breath |
| **中等振荡** (~7%) | 3, 4 | 1.0 | 1.0 | 半径小幅振荡，系统接近线性，T_rad = T_tan = T_breath |
| **极小振荡** (~6%) | 5 | 1.0 | **0.5** | 半径振荡极小但角速度出现高频谐波（2×基频），T_tan = T_breath/2 |

> **Agent 5 的特殊性**：虽然半径振幅仅 6.1%（与 Agent 3, 4 相近），但其角速度变化周期恰好是呼吸周期的一半。这表明角速度的谐波含量与径向振幅不是简单的一一对应关系——即使径向振荡很小，1/r² 的非线性在特定相位关系下仍能产生显著的高频谐波。

#### 集体量的周期一致性

尽管个体存在差异，集体量的周期一致性由以下因素保证：

1. **角动量近似守恒**：总角动量 L = Σ L_i 在极限环上涨落 < 1.5%
2. **平均半径与平均角速度的耦合**：
   
   ```
   ω_mean(t) ≈ L / (N · r_mean(t)²)
   ```
   
   由于 r_mean(t) 以周期 T_breathing 振荡，ω_mean(t) 也以**同一周期**振荡。
3. **r_mean² 的振荡周期 = r_mean 的振荡周期**：对于正弦型振荡，r² 的周期与 r 相同。

### 与 2D 阻尼振荡器的结构类比（径向-切向视角）

简单 2D 阻尼振荡器

```
ẍ + k₁ẋ + k₂x = 0,  x ∈ ℝ²
```

的解析解给出了径向-切向周期的精确关系：

```
r²(t) = x₁² + x₂² = e^{-k₁t} · [R₁²cos²(ωt−φ₁) + R₂²cos²(ωt−φ₂)]

dot_θ(t) = (x₁v₂ − x₂v₁) / r²
         = R₁R₂·ω·sin(φ₂−φ₁) / [R₁²cos²(ωt−φ₁) + R₂²cos²(ωt−φ₂)]
```

其中 ω = √(4k₂ − k₁²)/2。分母的 cos² 项使 dot_θ 以周期 T = π/ω 振荡：

```
T_r² = T_dot_θ = π/ω = 2π/√(4k₂ − k₁²)
```

**数值验证**（k₁=k₂=1, x(0)=(1,0), ẋ(0)=(0,1)）：

| 量 | 理论值 | 数值观测 |
|----|:------:|:--------:|
| ω = √(4k₂−k₁²)/2 | 0.8660 | — |
| T_r² = T_dot_θ = π/ω | 3.6276 s | 3.6275 s |

#### 与围捕系统的对比

| 系统 | T_rad（径向） | T_tan（切向） | T_rad/T_tan |
|------|:-----------:|:-----------:|:----------:|
| 2D 阻尼振荡器 | T_r² = π/ω | T_dot_θ = π/ω | **1.000** |
| 围捕高频分支（集体） | T_breathing | T_breathing | **1.000** |
| 围捕高频分支（Agent 1） | 2T_breathing | 2T_breathing | **1.000** |
| 围捕高频分支（Agent 5） | T_breathing | T_breathing/2 | **2.000** |

> **关键结构共性**：在 2D 阻尼振荡器中，角动量严格守恒（L = r²·dot_θ = const），因此 T_tan = T_rad 严格成立。在围捕系统的**集体层面**，总角动量近似守恒（涨落 < 1.5%），因此 T_tan_mean = T_rad_mean = T_breathing 也严格成立。但在**个体层面**，agent 角动量不守恒，导致 T_tan_i 与 T_rad_i 可以不同。

#### 有效刚度修正

围捕系统的呼吸周期比用简单公式直接代入的值小得多：

| k₁ | k₂ | 简单公式 T = 2π/√(4k₂−k₁²) | 观测 T_breathing | 比值 |
|:--:|:--:|:------------------------:|:----------------:|:----:|
| 0.5 | 0.5 | 4.750 s | 2.486 s | 0.52 |

因为排斥力增加了系统的有效刚度。将排斥力视为对 k₂ 的修正：

```
ω_eff² ≈ 12.8·k₂  （从 2D 扫描拟合）
k₂_eff = (ω_eff² + k₁²/4) / 4 ≈ 1.616  （k₁=k₂=0.5 时）
T_pred = 2π/√(4·k₂_eff − k₁²) ≈ 2.521 s
```

| 量 | 值 | 误差 |
|----|:---:|:----:|
| 观测呼吸周期 | 2.486 s | — |
| 用 k₂_eff 预测 | 2.521 s | **1.4%** |

> **核心结论**：围捕系统的呼吸周期与简单 2D 振荡器的径向-切向周期有相同的数学结构。区别在于围捕系统有非线性排斥力，它通过有效刚度 k₂_eff = k₂ + k_rep 来修正周期公式：
>
> ```
> T_breathing = 2π / √(4·k₂_eff − k₁²)
> ```
>
> 其中 k_rep 是排斥力对有效势能曲率的贡献。

### 小结

```
径向周期 T_rad：
  − 集体平均半径 r_mean(t) 的振荡周期 = T_breathing
  − 个体 agent r_i(t) 的振荡周期 ∈ {T_breathing, 2×T_breathing}

切向周期 T_tan：
  − 集体平均角速度 ω_mean(t) 的变化周期 = T_breathing
  − 个体 agent ω_i(t) 的变化周期 ∈ {T_breathing/2, T_breathing, 2×T_breathing}

旋转周期 T_rot：
  − 个体 agent 角位置 θ_i(t) 转一圈的时间 ≈ 9.1 s
  − 与呼吸周期 T_breathing 无直接关系
  − T_rot = 2π/|ω_i| ≈ 2π/0.68 ≈ 9.2 s

集群中心：
  − r_cm ≈ 0（质心在原点），角速度退化
  − 但 ω_mean(t) 仍有明确周期 = T_breathing

核心等式：
  − T_rad_mean = T_tan_mean = T_breathing  （集体层面严格成立）
  − T_rad_i = T_tan_i  （个体层面，仅当 L_i 近似守恒时成立）
  − T_rot_i ≠ T_breathing  （旋转周期与呼吸周期无关）
```

## 双稳态与多吸引子结构

### 两个呼吸分支

通过测试不同的初始条件，发现了**两个共存的呼吸极限环分支**：

| 分支 | ω_eff/√k₂ | 周期 T (k₁=k₂=0.5) | 振幅 | 典型初始条件 |
|------|:---------:|:------------------:|:----:|------------|
| **高频分支** | ≈ 3.5 | 2.5 s | 5-30% | case3.py 反例及扰动 |
| **低频分支** | ≈ 1.42 | 6.2 s | 5-10% | 扰动正五边形（pert=2.0）|

### 低频分支的参数规律

对低频分支（IC3：扰动正五边形，seed=99，pert=2.0）：

| k₁ | k₂ | T (s) | ω_eff/√k₂ | 振幅 |
|:--:|:--:|:-----:|:----------:|:----:|
| 0.5 | 0.3 | 8.09 | 1.42 | 9.7% |
| 0.5 | 0.5 | 6.24 | 1.42 | 5.6% |
| 0.5 | 0.7 | 5.25 | 1.43 | 4.8% |
| 0.6 | 0.5 | 6.26 | 1.42 | 6.2% |

> **关键发现**：低频分支的 ω_eff/√k₂ ≈ 1.42，**与 k₁ 和 k₂ 几乎无关**（变化 < 1%）。这与高频分支的行为截然不同。

### 高频分支的参数规律（三个 IC 的对比）

| IC | k₁ | k₂ | T (s) | ω_eff/√k₂ | 振幅 | 公式误差 |
|----|:--:|:--:|:-----:|:----------:|:----:|:--------:|
| IC1 (pert0.3) | 0.5 | 0.5 | 2.56 | 3.47 | 27% | +4.4% |
| IC1 (pert0.3) | 0.4 | 0.5 | — | 3.50 | — | +4.4% |
| IC1 (pert0.3) | 0.6 | 0.5 | 2.57 | 3.46 | 22% | +0.9% |
| IC2 (pert0.5) | 0.5 | 0.5 | 2.54 | 3.49 | 16% | +1.7% |
| IC2 (pert0.5) | 0.4 | 0.5 | — | 3.59 | — | +1.7% |
| IC2 (pert0.5) | 0.6 | 0.5 | 6.28 | 1.42 | 18% | 跳变到低频 |

> **关键发现**：高频分支的 ω_eff/√k₂ ≈ 3.5，与 2D 扫描结果一致。公式 ratio = 3.78 − 0.81·k₁ + 0.39·k₂ 对高频分支误差 < 5%。

### 多吸引子共存

系统存在**三个共存的吸引子**：

1. **旋转平衡**：刚体旋转，无呼吸（正五边形初始条件 → 此）
2. **高频呼吸极限环**：ω_eff/√k₂ ≈ 3.5（case3.py 反例及扰动 → 此）
3. **低频呼吸极限环**：ω_eff/√k₂ ≈ 1.42（大扰动正五边形 → 此）

**关键现象**：
- IC2（case3_pert0.5）在 k₁=0.6 时从高频分支**跳变**到低频分支（T 从 2.5s 跃迁到 6.3s）
- IC1（case3_pert0.3）在 k₁=0.3 时出现**中间分支**（ratio=2.36，amp=64%）
- 同一初始条件在不同参数下可能收敛到不同分支，表明存在复杂的吸引子盆地结构

### 物理含义

低频分支的 ω_eff/√k₂ ≈ 1.42 接近自然旋转频率（ratio=1），表明低频呼吸模式更接近刚体旋转。高频分支的 ratio ≈ 3.5 表明呼吸振荡的频率远高于约束力平衡频率。

两个分支的共存意味着系统在呼吸模式上存在**两种不同的振荡机制**：
- 高频分支：由约束力和排斥力之间的快速平衡驱动
- 低频分支：由系统的整体惯性主导，接近自然旋转频率

8. **径向-切向周期比的参数依赖性**：

../.venv/bin/python -c "
import sys; sys.path.insert(0, 'simulation')
from fencing_ode import integrate, evaluate
from scipy.signal import find_peaks
import numpy as np
XI0 = np.array([[-10.584563, -12.532987],[-5.382648,5.904905],[-0.177347,9.17592],
                [-7.352506,-4.805249],[-6.288338,12.43583]])
VT0 = np.array([[3.528048,-1.274511],[-0.511988,-1.485443],[1.972071,-3.679895],
                [-3.460489,-0.767699],[-2.039248,2.7618]])
for k in [0.2, 0.3, 0.4, 0.5]:
    rhs, sol = integrate(XI0, VT0, 5.0, 9.0, k, k, 600.0, 'LSODA', 1e-6, 1e-8)
    t = np.arange(100, 600.1, 0.2)
    p, _ = evaluate(sol, 5, t)
    r = np.mean(np.linalg.norm(p, axis=2), axis=1)
    pe, _ = find_peaks(r, prominence=0.001, distance=10)
    T = np.mean(np.diff(t[pe])) if len(pe) > 2 else 0
    print(f'k={k:.1f}: T={T:.4f}, ratio={2*np.pi/T/np.sqrt(k):.4f}')
"
```
