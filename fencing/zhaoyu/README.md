## 研究脉络

主线：围绕 **分布式平均跟踪 / 动态平均一致性（DAT/DAC）**——让多智能体在仅用邻居信息、且参考信号动态未知的条件下，跟踪多个时变参考信号的平均值，并逐步解决“信息受限 → 精度与鲁棒性 → 收敛速度 → 通信开销 → 拓扑一般性与隐私”这条递进链条。

1. **2015–2017｜奠基：输出受限下的 DAT 与“静态/自适应增益”范式**
   从只依赖相对输出测量（[1] CCC 2015）、仅相对输出信息下的分布式平均计算（[2] IJRNC 2016）出发，[3] Automatica 2017 提出 **edge-based 框架**，用 **边界层（boundary layer）** 技术消除连续算法的抖振，并给出静态增益（渐近跟踪）与自适应增益（误差一致最终有界、指数收敛到可调小集）两类算法——这成为后续工作的基本设计模板：**连续/无抖振 + 全分布式（自适应免全局信息）**。

2. **2017–2019｜非线性参考信号与鲁棒性**
   参考信号由 **Lipschitz 型非线性动力学** 生成时，[4] IWCSN 2017 用 **状态依赖增益（state-dependent gain）** 实现鲁棒 DAT 且不要求相同初值；[6] TCYB 2019 将其系统化，[5] YAC 2018（二值测量、未知有界输入下的有限时间平均估计）与 [7] TNNLS 2019（二阶非线性系统）则把“有限时间”引入这一非线性场景，并配套 Lyapunov 收敛时间估计。

3. **2019–2023｜收敛时间可控：有限时间 → 固定时间 → 指定时间（appointed-time）**
   [7] 有限时间精确收敛；[9] TCSII 2020 针对有界/Lipschitz 型导数给出 **固定时间实用型** 算法；[12] TCSII 2022 面向 **有向网络** 引入 surplus 变量记录平均值的漂移，实现 **指定时间** 平均一致性（收敛时间与其它参数无关、可按任务指定）；[15] TCSII 2023 进一步提出 **整体规划 + 多步控制（HPMSC）** 框架，实现 **零误差 appointed-time DAC**，且无需已知参考信号导数上界等额外条件。技术手段：运动规划、时间投影、矩阵扰动分析。

4. **2019–2023｜通信与计算效率：事件触发（ETDAT）**
   [8] SSCI 2019 首次把事件触发机制引入 DAT，[10] CDC 2020 / [11] TCNS 2021 解决 **无速度测量 + 事件触发通信** 下的鲁棒 DAT；[13] TAC 2022 系统给出同质/异质系统的静态增益（采样+模型保持，双触发函数分别管理估计器与控制器）与光滑动态增益（边界层+自适应，抑制抖振并去掉全局信息需求）事件触发平均跟踪算法；[14] IFAC 2022 推广到异质多智能体；[16] TCYB 2023 首次处理 **Lipschitz 非线性多智能体** 的 ETDAT，自适应增益版本完全分布式，并在 Watts-Strogatz 小世界网络上验证。

5. **2022–2025｜拓扑一般化与隐私安全：surplus → integral surplus**
   从 [12] 的 surplus 思想出发，[18] TAC 2025 提出 **integral surplus**，在 **强连通但未必平衡** 的有向图上实现 DAC，稳态误差有界且可由参数调节；[17] TAC 2025 进一步面向 **可能非平衡的有向网络**，建立积分剩余型 **指定时间** 控制框架，并给出隐私攻击模型与 **状态分解** 隐私保护方案，使外部窃听者无法获取智能体的隐私敏感数据——即“**指定时间性能 + 拓扑最一般 + 隐私保护**”三者兼得。

一句话总结：[1]–[3] 立框架，[4]–[7] 加非线性与有限时间，[9][12][15] 把收敛时间变成可设计的“指定时间”，[8][10][11][13][14][16] 把通信开销压到事件触发，[12][17][18] 把拓扑从无向/平衡推进到有向/非平衡并叠加隐私保护。

## 关键技术：Surplus（剩余变量）简介

非平衡有向图下 $\mathbf{1}^{\top}L=\mathbf{0}^{\top}$ 失效造成 **average shift**；surplus 用一个一维本地记账变量 $s^{i}$ 使 $\sum_i(s^{i}+y^{i})$ 守恒，从而补偿漂移。其源头是 Cai & Ishii 2012 的 *surplus-based averaging*（okb `7269`），与 push-sum / ratio consensus 同源——**push-sum 用「除法归一化」消缩放，surplus 用「减法记账」消漂移**。本系列的演进为：surplus（`6180`）→ integral surplus（`6235`、`6219`）→ nonsmooth surplus（`3795`）。

**详见 → [surplus.md](./surplus.md)**（含概念推导、push-sum 对照表，以及 13 篇相关文献的 okb 索引）；最新一篇 `3795`（nonsmooth surplus）的**问题 / 算法 / 创新点公式化整理**见 → [3795-nonsmooth-surplus.md](./3795-nonsmooth-surplus.md)
