## 1. 本轮改动的三个直接结论

| 结论 | 数据（仿真结果） | 含义 |
|---|---|---|
| 单周期零化在完整三维耦合模型上仍然成立 | 名义工况下 `max_{t≥T}‖e‖` = 4.3×10⁻⁵ rad（PD 为 1.4×10⁻³），实测调节时间 2.74 s vs 5.04 s；t = T 处残差 1.7×10⁻⁵ 与步长成正比（Ts 减半 → 8.3×10⁻⁶） | PDF 机制不依赖“合成模型”，但在数值上受离散化限制 |

## 2. 可拓展方向（按“投入小 / 产出大”排序）

### 2.1 结构化 / 多率延迟反馈（最直接、最有理论增量）

- **动机**：条件数 7.4×10³ 与“归一化增益失效”实验说明，问题出在 `K_c` 的构造对所有关节共用
  同一个 `h` 与 `R_h(θ)`。
- **做法**：把 Gramian 按关节分块（`W_c = blkdiag(W_c^{(i)})`），允许每块使用不同的
  `h_i`（例如按 `ω_i = √K_p,i` 取 `h_i = c/ω_i`），并把 `W_c` 的条件数作为设计目标；
  也可用状态缩放 `z̃ = Dz` 统一写成同一周期结构，从而保留定理 1 的证明框架。
- **预期产出**：`cond(W_c)` 从 10³–10⁴ 降到 10¹ 量级；名义工况残余误差再降 1–2 个数量级；
  可写成“多率周期延迟反馈的单周期零化定理”。
- **风险**：不同 `h_i` 会破坏“act-and-wait”的统一时序，需要重新推导周期映射。

### 2.2 饱和感知的零化机制（工程价值最高）

- **动机**：3° 初始误差工况下 3.6% 步数饱和，饱和窗口内单周期零化不再成立，
  峰值误差 7.3×10⁻² rad；而当前控制律无积分器，所以“不会 windup”，但也“不会自愈”。
- **做法**：
  1. **事件触发重启窗口**：当 `‖z‖` 回到执行器包络内时，以当前时刻为新 `T_o` 重启
     `[T_o, T_o+2h]` 窗口（控制器只需保存一个延迟缓冲，改动极小）；
  2. **可行性条件**：把 `(e(0), τ_max, h)` 映射为可零化集合，给出“初始误差上限”解析式
     （对本文参数，肩关节 1° 误差即需 ≈11 N·m）；
  3. **借用 [259] 的固定时间抗饱和补偿器**：其辅助变量 η 在饱和消失后固定时间归零，
     适合与本控制律串联（本文已实现该补偿器接口，可直接复用）。
- **预期产出**：饱和工况的峰值误差下降一个数量级；给出“饱和占空比 ≤ x% 时仍保证预设时间”的条件。
- **风险**：事件触发会使定理陈述变成“分段预设时间”，需重新写稳定性证明。

### 2.3 任务空间 + 基座姿态一体化（把方法推到“可执行任务”层级）

- **动机**：目前只保证关节空间跟踪；在轨服务真正要求的是末端轨迹 + 基座姿态不漂。
  本文测得基座反应位移约 5 cm（10 s 机动），在任务空间实现中会变成传感器系偏差。
- **做法**：用广义雅可比 + 阻尼最小二乘生成关节参考（论文式 (34) 已给出），
  上层用反应零空间（RNS）分配基座姿态保持；规划层用 [nanos2015avoiding] 的动态奇异
  规避思路检查参考轨迹；把任务空间残差显式写入 practical bound。
- **预期产出**：末端误差 10⁻³ m 量级 + 基座姿态漂移 <0.1° 的联合指标；
  与 [259]、[1486]、[3] 的末端误差/收敛时间可直接对比。
- **风险**：任务空间层与预设时间层的时标需要协调，否则“预设时间”只对关节通道成立。

### 2.4 非零动量 / free-flying 工况

- **动机**：假设 1（零初始动量）在实际任务中常被反作用轮/推力器破坏。
- **做法**：采用增广动量模型 [nanos2017momentum, nanos2023fullpose]，把基座速度写成
  `ẋ_b = -H_b⁻¹(H_bm q̇ + L_0)`，此时降阶模型多出一个常值/慢变输入通道；
  延迟反馈需要零化的状态维数增加（可把 `L_0/H_b` 当作附加扰动交给 PTDO）。
- **预期产出**：动量—时间—精度三者的权衡曲线（给定 L_0 下可达的预设时间）。
- **风险**：工作空间随动量收缩，可能出现“物理上不可达”的预设时间。

### 2.5 采样/量化实现的理论化

- **动机**：当前 t = T 处残差完全由 Euler 步长与延迟缓冲采样决定（Ts 减半 → 残差减半）。
- **做法**：对误差通道（线性时变延迟系统）做**精确离散化**（`expm` 分段），
  推导离散单周期映射 `Δ_K,d`，把 `‖Δ_K,d‖`、延迟缓冲量化误差、输入量化
  [hu2025preassigned] 一起写进 practical bound；必要时用“零阶保持 + 分数延迟插值”。
- **预期产出**：可证明的离散时间界，替代目前“经验上随步长线性下降”的观察。
- **风险**：精确离散化 + 周期映射的谱分析计算量较大，需离线完成。

### 2.6 更真实的被控对象

- 挠性附件（[2049] 的主动振动控制思路）、关节摩擦（LuGre + RL 调参 [3843]）、
  执行器动态、以及**接触瞬间的模型切换**（捕获冲击 [2050]、动量传递 [1298]）。
- 具体可做：接触前用 PDF+PTDO；接触瞬间冻结延迟缓冲、切换为阻抗/动量传递控制；
  接触后重新初始化 `T_o` 并重启零化窗口。这正好接上 `capture.md` 的阶段划分。

### 2.7 实验与基准

- **动机**：调研报告指出全领域只有 ETS-VII 等极少数硬件结果，且“同一平面二杆 / 7-DOF
  混用、指标不统一”，结果不可横比。
- **做法**：把本文的参数集、`τ_max`、收敛时间定义、峰值力矩、饱和占空比、基座漂移
  作为标准指标公开；在气浮台上做 2–3 自由度降阶验证（延迟缓冲与力矩限幅是最依赖硬件的两环）。
- **预期产出**：一篇“可复现基准 + 实验验证”的后续论文，同时反过来验证 2.2 的饱和结论。
