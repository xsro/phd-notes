# 文献 259 与 2984 仿真参数对比

> 知识库 okb 中两篇同作者（Bo Dou, Xiaokui Yue）的 FFSM 分数阶滑模控制论文。本文只对比**仿真设置与参数**，不比较理论推导。
>
> - **#259**：*Fractional-Order Sliding Mode Control for Free-Floating Space Manipulator With Disturbance and Input Saturation*, 2025, DOI `10.1002/rnc.7826`（考虑扰动 + **输入饱和**）
> - **#2984**：*Disturbance observer-based fractional-order sliding mode control for free-floating space manipulator with disturbance*, Aerospace Science and Technology, 2023, DOI `10.1016/j.ast.2022.108061`（只考虑扰动）

---

## 一、总体判断（先给结论）

| 维度 | 差异程度 | 说明 |
|---|---|---|
| 机械臂**本体参数** | ⭐ 几乎无差异 | 7-DOF 模型的两张参数表**逐项完全相同**（同一实验室同一模型），单位/质量/惯量/质心位置一致 |
| 仿真**机构与场景** | ⭐⭐⭐⭐ 差异大 | 2984 主打 2D 平面 3-DOF（另加 3D 7-DOF 验证）；259 只做 3D 7-DOF + 一个二阶线性系统 |
| **扰动幅值** | ⭐⭐⭐⭐⭐ 差异很大 | 2984：3 N·m 常值 + 0.3 N·m 正弦/分形噪声；259：仅 0.2 N·m 与 0.05 N·m 正弦 → 约 **15 倍** |
| **输入饱和** | ⭐⭐⭐⭐⭐ 本质区别 | 259 明确给出 $\tau_{max}=20$ N·m 并设计抗饱和补偿器；2984 **无饱和限制**（明确列为 future work） |
| **参数不确定性** | ⭐⭐⭐ 差异大 | 259 Part II 把第 7 杆实际质量改为 40 kg（标称 18.1 kg，约 +121%）；2984 仿真中不引入 |
| **初始速度** | ⭐⭐⭐ 差异大 | 2984 的 2D 算例初速 $[-2,2,-2]$ rad/s（非零）；259 全部零初速 |
| 控制器/观测器**增益** | ⭐⭐ 中等 | 同类参数相差约 2–5 倍，且有 2D(3 关节) 与 7 关节维度差别 |

**一句话**：本体模型可以直接互相复用；但**仿真工况（扰动幅值、饱和、不确定性、初速）差别很大**，控制增益也随对象维度和工况重新整定，不能把一篇的增益直接搬到另一篇的场景里。

| 项目 | #259 (2025) | #2984 (2023) |
|---|---|---|
| 验证用简化系统 | 二阶系统 $\dot x_1=x_2,\ \dot x_2=u+\phi_d$，$\phi_d=0.1+0.2\sin t$ | 无 |

## 三、系统扰动设置（差异最大处）

| 项目 | #259 | #2984 |
|---|---|---|
| 形式 | 正弦叠加：$\tau_{d,1..4}=0.2\sin(0.1t+\varphi_i)+0.05\sin(0.01\pi t+\varphi_i)$，$\tau_{d,5..7}=0.05(2\sin(0.1t+\pi/6)+\sin(0.01\pi t+\pi/6))$ | $\tau_d=[3,\ 3+0.3\sin(\pi t),\ 3+0.3\varphi_d(t)]^T$（2D）；3D 为 $\tau_{d,1}=\tau_{d,4}=3$，$\tau_{d,2}=\tau_{d,5}=0.3\sin(\pi t)$，$\tau_{d,3}=\tau_{d,6}=0.3\varphi_d(t)$，$\tau_{d,7}=0.1$ |
| 幅值量级 | ≈0.05–0.2 N·m | 3 N·m（常值） + 0.3 N·m 振荡 |
| 不可微分量 | 无 | 有，$\varphi_d(t)=\sum_{r=0}^{N}b^{-r\nu_c}\sin(b^rt)$，$N=200,\ b=7,\ \nu_c=0.9$ |
| 目的 | 在**饱和 + 不确定性**下验证鲁棒性 | 专门验证**分数阶观测器**对连续不可微扰动的估计能力 |

> 这是两篇论文最不能直接对齐的地方：2984 的扰动比 259 大约 15 倍，且刻意包含分形（处处不可微）分量；259 的扰动很小，主要压力来自 ±20 N·m 饱和与 121% 的连杆参数误差。

## 八、如果要复现/统一仿真，需要注意

1. **本体模型可直接复用**：7-DOF 那张表（质量、惯量、$a_i/b_i$、$\alpha_i/l_i/d_i$）两篇完全一致，取任意一篇即可。
2. **扰动量级必须重设**：把 2984 的 3 N·m 级扰动配 259 的 ±20 N·m 限幅，饱和会长期存在；反之把 259 的 0.2 N·m 扰动配 2984 的无饱和设置，抗饱和补偿器基本不起作用、看不出效果。
3. **增益不能跨场景搬用**：259 的观测器增益是 diag(10)（有限时间结构），2984 是 2–5（分数阶结构），混用会破坏有限时间/固定时间的稳定性条件。
4. **初速差异会影响初始峰值力矩对比**：2984 的 2D 算例有 $\pm2$ rad/s 初速，259 全部零初速，两篇的"初始力矩极大"现象成因不完全相同（2984 主要是扰动过估计 + 初始误差；259 还叠加了饱和与参数不确定性）。
5. **共同点可以直接引用**：分数阶滑模结构参数 $\xi=0.9,\ b=0.8,\ r_1=0.5,\ r_2=1.5,\ \delta=0.1$，以及 $\lambda_1/\lambda_2$、$c_1/c_2$ 的对角增益设计思路在两篇中一致，可作为同一课题组的"默认整定起点"。
