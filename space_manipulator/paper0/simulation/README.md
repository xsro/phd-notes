## 3. 文献 259 的模型

### 3.1 运动学（Eq (1)–(5)）

末端速度由基座与关节速度线性组合：

```
ẋ_e = J_be ẋ_b + J_me θ̇_m                                  (1)
```

零初始动量 ⇒ 基座速度由关节速度唯一确定：

```
L = H_b ẋ_b + H_bm θ̇_m = 0  ⇒  ẋ_b = -H_b⁻¹ H_bm θ̇_m        (2)(3)
ẋ_e = J θ̇_m,   J = J_me - J_be H_b⁻¹ H_bm                    (4)
ẍ_e = J θ̈_m + J̇ θ̇_m                                          (5)
```

### 3.2 动力学（Eq (6)–(10)）

完整方程

```
[ H_b   H_bm ] [ ẍ_b ]   [ C_b1 C_m1 ] [ ẋ_b ]   [  0  ]
[ H_bmᵀ H_m  ] [ θ̈_m ] + [ C_b2 C_m2 ] [ θ̇_m ] = [ τ_m ]     (6)
```

消去基座变量后得到关节空间等效模型（**Schur 补**）：

```
H_θm θ̈_m + C_θm θ̇_m = τ_m                                  (8)
H_θm = H_m - H_bmᵀ H_b⁻¹ H_bm
C_θm = C_m2 - C_b2 H_b⁻¹ H_bm - H_bmᵀ H_b⁻¹ (C_m1 - C_b1 H_b⁻¹ H_bm)
```

计入参数摄动、外扰与输入饱和（Eq (9)(10)）：

```
H_θm θ̈_m + C_θm θ̇_m = τ_mc + Δτ_m + τ_d                     (10)
Δτ_mi = sat(τ_mci, τ_i,min, τ_i,max) - τ_mci
τ_d  = τ_e - (ΔH_θm θ̈_m + ΔC_θm θ̇_m)        (集总扰动)
```

性质：`H_θm` 对称正定；`Ḣ_θm - 2C_θm` 反对称。

### 3.3 控制律（Eq (15)(35)(36)(37)(44)(50)(57)）

```
滑模面   s = ė + C1 χ(e) + C2 · D^{ξ-1}[sig(e)^b]                    (15)
         χ(e) = sig(e)^{r1}                       , |e| ≥ δ
              = kχ1 e + kχ2 sig(e)^{r2}           , |e| < δ
         kχ1 = (r1-r2)/(1-r2)·δ^{r1-1},  kχ2 = (1-r1)/(1-r2)·δ^{r1-r2}

观测器   p = H_θm θ̇_m
         ṗ̂ = k1 φ1(p-p̂) + C_θmᵀ θ̇_m + τ_mc + Δτ_m + τ̂_d            (35)
         τ̂̇_d = k2 φ2(p-p̂)                                          (36)
         φ1 = μ1 sig(e_p)^α + μ2 sig(e_p)^β
         φ2 = μ1²α sig(e_p)^{2α-1} + μ1μ2(α+β) sig(e_p)^{α+β-1}
              + μ2²β sig(e_p)^{2β-1}

补偿器   η̇ = -L_η (kη1/ρ1) tanh(|η|)^{1-ρ1} cosh(|η|)² sign(η)
             - L_η kη2 sig(η)^{ρ2} + Δu                                (37)
         Δu = H_θm⁻¹ Δτ_m
         L̇_η = -kL1 L_η - kL2 L_η^{1/2} + kL1 P^L        , Δu ≠ 0      (44)
              = Proj(kL3 L_η^{a1} + kL4 L_η^{-a2} + cL), Δu = 0

控制     ddq_r = ddq_d + C1 h(e) ė + C2 D^ξ[sig(e)^b]
                + [上述 η 项] + λ1 y + λ2 sig(y)^{ρ3},  y = s - η        (50)
         τ_mc = C_θm θ̇_m + H_θm ddq_r - τ̂_d                           (57)
```

对应关系：Eq (50) 的恒等式说明 `ẏ = -λ1 y - λ2 sig(y)^{ρ3} - J(d - d̂)`。

原文的 Case (1)(2)(3) 分别对应 **FTASC (Eq 37/44)**、**FTAC [29] (Eq 46)**、
**无补偿**；Part II 的对比对象是 **FOSM (Eq 77)**，即把 Eq (15) 中的非线性项
`C1χ(e)` 换成线性项 `C1 e`。

## 5. 实现说明与与原文的差异

### 5.1 任务空间 → 关节空间

原文的一级任务是末端笛卡尔跟踪（Eq 48/50/51），二级任务是基座姿态稳定
（Eq 52–56，需要 `H̄_w/H̄_m/C̄_b1/C̄_m1` 的 v/w 分块、四元数误差与零空间投影）。
本工程把 Eq (15) 的滑模面作用于**关节误差**，控制律仍为 Eq (50)(57) 的结构。
理由：使 PDF（本工程方法，本质是关节空间）与 FONTSM 面对完全相同的误差通道，
比较公平；末端误差另由正运动学 `ffsm259_model` 评估（表中 `EE-RMS` 列）。
若需完全复现原文的任务优先级结构，可在 `fonsm259_step.m` 中把
`e, ė, C1, C2` 换成 `x_e^d - x_e` 与 `J_E⁺(...)`。

### 5.2 分数阶算子

`D^{ξ-1}[·]`（阶 −0.1）与 `D^ξ[·]`（阶 0.9）都用 Grünwald–Letnikov 离散：

```
w_0 = 1,  w_k = w_{k-1}·(1 - (ν+1)/k),   D^ν f ≈ h^{-ν} Σ_k w_k f(t-kh)
```

`D^ξ[sig(e)^b]` 用 Caputo 定义改写为 `D^{ξ-1}[d/dt sig(e)^b]` 以避免 `t^{-0.1}`
奇异；短记忆长度 `cfg.mem_len = 750`（1.5 s @ Ts = 2 ms），长时记忆的尾部被截断。
所有 FONTSM 变体共用同一算子，因此对比结论不受影响。

### 5.3 增益标定系数 κ

Table 3 的增益是按原文的笛卡尔误差量级（mm）设计的。直接用于本对象的关节空间
（`M_θm` 对角元 0.28–345 kg·m²）时，初始指令力矩可达 **~450 Nm**，即
`τ_max = 20 Nm` 的 20 倍以上，全程饱和且闭环发散。为此对 259 控制器的修正通道
引入单一标定系数：

```
ddq_r = ddq_d + κ·( C1 h(e) ė + C2 D^ξ[sig(e)^b] + [η 项] + λ1 y + λ2 sig(y)^{ρ3} )
```

κ 不改变控制律结构。`calib_kappa.m` 的扫描结果（0.5° 初始误差）：

| κ | \|e(T)\| [rad] | RMS_ss | max\|τ\| [Nm] | 饱和占空比 |
|---|---|---|---|---|
| 0.005 | 3.18e−03 | 7.80e−03 | 17.7 | 0.0 % |
| 0.010 | 1.97e−03 | 1.20e−02 | 23.1 | 4.6 % |
| 0.020 | 4.35e+00 | 发散 | 939.7 | 92.0 % |

⇒ **κ ≈ 0.015 是本对象的稳定边界**，主脚本默认 `κ = 0.01`。
主脚本同时输出 `κ = 1`（Table 3 增益直用）的结果作为对照，该工况下 FONTSM
各变体全程饱和并发散（FTAC 甚至发散到 1e18）。

### 5.4 Table 1 的内部不一致（重要）

`dou_yue_259_check_consistency.m` 的输出表明：按 DH 行计算的连杆长度序列与
`|a_i + b_i|` 序列**整体错一位**：

```
DH 行   |[l_i,0,d_i]|              : [0.18 0.22 0.20 1.224 1.22 0.20 0.30]
a_i+b_i |a_i + b_i|                : [0.22 0.20 1.224 1.22 0.20 0.30 0.10]
DH 行 右移一位                     : [0.22 0.20 1.224 1.22 0.20 0.30]   ← 完全一致
```

且 `a_3 = [0.6,0,0]`、`b_3 = [0.6,0,0.24]` 说明连杆 3 长 1.2 m。因此本实现采用
**错位读法**：

```
连杆 i (关节 i → i+1) :  T = Rz(θ_i) Tz(d_{i+1}) Tx(l_{i+1}) Rx(α_i)
基座质心 → 关节 1     :  沿 z_0 平移 d_1 = 0.18 m
连杆 7 末端            :  d_8 = 0.10 m  ( = |a_7 + b_7| )
```

这样 `a_i` 给出的质心位置始终落在连杆内部。若按不错位的教科书读法，连杆 3
只有 0.20 m，而其质心偏置为 0.6 m（质心在杆外），物理上不合理。

另外 `|b_0| = 1.18 m` 与 `d_1 = 0.18 m` 不自洽（疑为原文排版错误），
本实现取 `d_1`。

### 5.5 PDF 增益的来源

`build_pdf_gain.m` / `pdf_gain_at.m` 来自原 `main_ffsm_pdf_tracking_yan_params.m`
的局部函数（该脚本已删除，见 §1.2），现为独立文件，默认 `n_grid = 4001`，
`W_c` 条件数 `cond(W_c) = 4.9e11`。

### 5.6 PTDO 参数整定

本工程方法的预设时间扰动观测器（`ptdo_step.m`，论文 Eq (19)-(22)）参数：
`T_o = 1 s`、`η = 0.3`、`σ = 0.4`，内部时间常数 `T_c` 需与被控对象的时间尺度匹配。
`tune_ptdo.m` 的扫描结果（PDF+PTDO，其余设置同主脚本）：

## 6. 结果

### 6.3 结论要点

1. **参数一致性**：被控对象的全部物理参数、初始状态、扰动力矩、饱和限幅都取自
   文献 259；模型经 Robotics System Toolbox 交叉校核（正运动学 2.3e−16 m，
   固定基座质量矩阵 8.5e−16）。
2. **无扰动**：PD 与 PDF 都可到 1e−14 rad；PDF 的 Gramian 条件数为
   4.9e11（与第 5 节"Gramian 病态"分析一致），实际退化为等效 PD。
3. **有扰动**：无观测器时 PD/PDF 残留 ~5e−02 rad。加上本文 PTDO（`T_c=5 s`）
   后达到 **3.96e−06 rad / 4.81e−06 rad（稳态）**，饱和率 7.2 %、`t_s=3.50 s`；
   加上 259 的 FTDOB 为 1.24e−04 rad。两者都优于 FONTSM 族（1.3e−03 ~ 2.0e−03）。
4. **PTDO 参数敏感性**：`T_c=1 s` 时观测器增益 `π/(ηT_c)`、`π/(σηT_c)` 过大，
   在 2 ms 步长下抖振明显（饱和率 17 %、`t_s=8.0 s`、终端 5.98e−05 rad）；
   观测误差（t≥2 s）的 RMS 从 `T_c=1` 时的 1.8e−02 降到 `T_c=5` 时的 4.8e−03。
   见 §5.6 / `tune_ptdo.m`。
5. **FONTSM vs FOSM**：同等条件下 FONTSM 稳态误差 1.20e−02，FOSM 3.39e−02，
   约 2.8 倍，与原文"非线性项加速收敛、提高精度"的结论方向一致。
6. **三种补偿器**：本工况饱和占空比仅 ~4.6 %，FTASC 与无补偿结果几乎相同；
   FTAC 与自适应增益略好（1.14e−02）。原文中补偿器的优势需在**强饱和**工况
   才明显（原文 Case 3 在 20 s 后发散）——这需要更大的初始误差或更小的 τmax，
   但本对象在强饱和下 `κ=0.01` 已接近稳定边界（§5.3），故未作为主结果。

   对本对象敏感，这一结论本身值得在论文中讨论。
